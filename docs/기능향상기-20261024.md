# 초록정원 연구기지 기능향상기 — 2026-10-24

## 탐구의 이유가 보이도록

정원은 땅을 칠하는 데서 끝나지 않고 물가·풀밭·건조 구역에 알맞은 식물을 직접 심도록 연결했다. 정원 상태가 바뀔 때 전체 입체 화면을 다시 만들던 경로는 기존 캔버스를 갱신하도록 바꿔 깜박임을 줄였다. 실제 잎자루 Meshy 단면은 납작한 구조가 확인되어 그대로 연결하지 않았으며, 현재 관찰 화면은 공기 공간을 단순화한 모형과 투명 그림을 사용한다. 실제 단면 사진이나 부력 시뮬레이션이라고 설명하지 않는다.

가방에서는 연잎을 본뜬 겉면과 입구 덮개의 역할을 나누었다. 겉면만 바꿔 물방울의 차이를 확인하고, 다음에는 덮개만 바꿔 안쪽 수첩이 젖는지를 비교한다. 학생은 한 부품을 바꾼 시험의 근거로 설명을 고쳐야 한다. 연잎 겉면만으로 열린 입구도 막힌다는 오개념을 결과로 확인할 수 있게 했다. 이후에는 비옷·신발처럼 생활 속 다른 물건에 적용하는 생각으로 이어진다. 실제 가방 GLB가 있는 것처럼 표시하지 않고 제공된 그림과 단순화 모형을 쓴다.

## 기록과 성취를 한 장에

연구노트는 다섯 탐구를 짧은 일기와 관찰 그림으로 돌아보는 형식으로 바꾸었다. 팝업에서 오늘 한 일과 발견을 읽고 기억 질문·읽었어 스티커로 확인한다. 완료하지 않은 탐구에는 완성된 학생 기록을 만들어 넣지 않는다.

엔딩은 정원을 되살린 리피 그림을 배경으로, 짧은 손글씨 탐험 일기를 한 장의 쪽지로 보여 준다. 사용자가 원하지 않은 정원·가방 반복 전시는 덜어냈다. 이 쪽지는 AI로 만든 활동 요약 예시이며 실제 학생 자필 기록이 아니다. 메인은 리피와 시작 버튼의 크기·위치를 조정해 탐험 초대가 먼저 보이도록 했다.

인트로·아웃트로 영상은 전체 화면과 시간별 자막을 지원한다. 기획자가 제공한 Suno 메인·엔딩 음악은 하나의 플레이어로 전환하고 영상 중에는 정지한다. 소리 설정은 기록 초기화와 별개로 유지한다.
