2. `npm run check`: server와 src/scripts의 모든 JavaScript 파일 문법 확인.
3. `npm test`: 저장·복원·학습 진행 상태 회귀 테스트.
4. `npm run build`: `dist/index.html`, `dist/src`의 JS/CSS, `dist/assets`의 WebP와 출처 문서를 복사. 원본 PNG·docs·tests·개발 서버·빌드 스크립트는 제외.

외부 패키지는 설치하지 않는다. 압축은 이미 제공된 bundled sharp를 사용한다. 다른 작업 환경은 기존 sharp 설치 경로를 `SHARP_MODULE_PATH`로 지정할 수 있다. 빌드 자체는 Node 기본 모듈만 쓴다.

`dist`가 이미 있으면 예정 파일만 갱신한다. 예정에 없는 파일이 있으면 해당 목록과 함께 중단하며 자동 삭제하지 않는다. 참조된 정적 파일이 누락되거나 원본 PNG를 참조하면 빌드가 실패하므로 통합 완료 후 실행한다.

## 호스팅과 운영

- 경로가 `/src/...`, `/assets/...`이므로 **도메인 루트에 dist 내용을 게시**하는 구성을 전제로 한다. 하위 디렉터리 호스팅은 경로 별도 조정이 필요하다.
- `npm start`는 소스 프로젝트를 확인하는 localhost 개발 서버다. `npm run preview`는 dist만 제공한다. 4323 포트의 실제 납품 폴더에서 28파일의 HTTP 응답 바이트 일치·WebP MIME을 확인했다.
- 학습 기록은 사용하는 브라우저의 localStorage에 저장된다. 다른 기기·다른 브라우저로 자동 이동하지 않는다. 브라우저 데이터 삭제 시 기록도 지워질 수 있다.
- 실제 호스팅 업로드와 공개 배포는 이번 스크립트에서 수행하지 않는다. 최종 배포 URL에서 시작→학습→저장→새로고침→복원 검증은 별도로 필요하다.
