# 03 인증서 신설 · 2026-11-22

실제 마지막 탐구를 마친 엔딩과 설정의 「인증서 받기」에서 연다. 기존 완주 기록을 보존하고 관리자 미리보기는 발급하지 않는다. 완료 판정·저장 형식·과학 내용은 그대로다.

- Codex 기본 이미지 도구로 잎·덩굴·씨앗·빛씨앗 테두리 1회 생성. WebP 132212바이트, 원본·프롬프트 `_source/generated-images/`.
- A4 가로, 학교·학년·반·번호·이름 손기입 빈칸. PDF 실측 학교 55.8mm·이름 68.3mm·높이 11.3mm. 저장 필드를 추가하지 않고 「인증서 만든 날」을 표시한다.
- 최신 사용자 지시에 따라 진행/성취 숫자 요약 없이 과학 수여 본문을 유지한다. 제목은 900과 얇은 획으로 보강했고, 공통 dialog 제목 25px 규칙에서 분리해 1280에서 44.5px로 보인다. PNG에도 같은 획을 그린다.
- macOS arm64, Node 24.22.2. 문법 검사 64파일·테스트 192/192·esbuild 빌드 통과. 세 뷰 전체 종이·버튼 표시, 겹침/입력 칸/콘솔 오류/4xx 0. 1280 종이 폭 75.6%. reduced-motion 애니메이션 0, 설정 재진입 확인.
- A4 가로 PDF 1쪽·PNG 2400×1697을 직접 열어 확인했다. 버튼·기입 안내는 출력에서 빠진다. 제작 표기는 잎 장식과 겹치지 않게 여백을 두었다.
- 기존 실제 완주 기록을 격리 브라우저에 넣어 확인했다. 전체 새 플레이나 실제 태블릿 검사로 확대하지 않는다.
