# 최종점검 — 초록정원 연구기지 0.5

## 최종 판정: 배포 보류

코드 보관용 GitHub 커밋과 공개 웹서비스 출시는 구분한다. 일반 모드 전체 탐구와 로컬 빌드는 통과했다. 공개 출시는 제공 제목·참고 캐릭터 자료의 이용 조건과 권리자 고지 확인, 전자칠판 보조 글자 개선이 남아 있다. 실제 기기·학생·학교 네트워크 검증과 공개 URL 검증은 수행하지 않았다.

## 중단 지점과 마무리

이전 작업은 새 지도·계절·공방 이미지와 `inquiry.js`, `spatial.js`, `fieldwork.css` 및 학습 판정 변경까지 저장된 상태였다. 최신 배포 산출물·전체 브라우저 검수·문서 반영·Git 연결은 완료되지 않았다.

- 그림 모드에서 도구 변경/정원 칠하기 후 입체 모드로 돌아가던 문제를 재현해 수정했다. 그림 선택을 같은 활동의 다시 그리기와 다음 정원 활동에서도 유지한다. 새 브라우저 세션의 영구 설정을 추가한 것은 아니다.
- 정원 심기 단계의 입체 안내를 `식물을 고르고 땅 누르기`로 바로잡았다.
- 버전을 0.5.0으로 맞추고 README·출처·기존 Three.js MIT 라이선스 연결을 보완했다. 기존 원문과 같은 라이선스를 중복 추가하지 않았다.
- Git을 초기화하고 지정 저장소를 origin으로 연결했다. 참고 교재·대용량 PNG·이전 ZIP·공유 대화 수집 원본·빌드 결과는 삭제 없이 Git에서 제외했다.

## 실행한 검증과 결과

- `npm run check`: JavaScript 22개 문법 검사 통과.
- `npm test`: 학습·저장·해금·비교 판정 27개 통과.
- `npm run build`: 58개 파일, 10,920,105 bytes. 소스 PNG·교재·문서·테스트·서버·검수 fixture는 배포에서 제외.
- 4341의 별도 로컬 origin에서 **관리자 해금 없이** 시작→10활동→5개 보상→보고→혼자 탐구 기록→선인장 적용→엔딩 완료. 관찰 중·엔딩에서 새로고침 복원 확인.
- 오답 후 재시도, 새 설계로 바꾸면 재시험 요구, 보통 천/열린 입구→연잎/열린 입구→연잎/덮개의 3회 시험과 각각의 설명 확인.
- 입체 정원 중앙 칸 클릭 칠하기, 그림 격자 칠하기·되돌리기·세 식물 배치·근거 확인. 연속 쓸기·멀티터치는 실물 기기로 확인하지 않았다.
- 전체 완료 후 교사용 화면 미리보기로 15화면×1280×800 / 1024×768 / 1920×1080 / 915×412 = **60상태** 측정. 문서 가로 넘침·태블릿/데스크톱 세로 넘침·44px 미만의 보이는 활동 버튼·깨진 이미지 없음. 낮은 화면은 스크롤 허용.
- 4342의 `--dist` 서버에서 새 기록으로 시작→첫 미션→관찰 선택→새로고침 유지 확인. 음소거, 초기화 확인/취소/실행, 브라우저 뒤/앞 이동도 확인. 마지막에는 초기화한 시작 화면을 미리보기로 남겼다.
- 확인한 앱 콘솔 오류·경고 없음. 검수 도구 자체의 화면 연결 지연 및 읽기 전용 측정 API 오류는 앱 오류와 구분했다.
- 측정 원본: `recovery-20261018/layout.json`. 화면: `map-1280.jpg`, `garden-1280.jpg`, `ending-1280.jpg`.
- 기존 일반 사용 주소 4318의 학생 기록은 사용·수정하지 않았다. 공개 호스팅·운영 배포는 수행하지 않았다.

## 배포 전 남은 조건 / 개선 우선순위

1. **21번 6→11:** 제공 자료의 이용 조건·권리자를 확인하고 실제 권리에 맞는 고지 작성. 확인 없이 제작 주체·권한 문구를 임의로 만들지 않는다. 출처·배포본 라이선스를 다시 검사한다.
2. **12번 7→11:** 전자칠판 모드의 안내·기록·입체 도구 글자 크기를 조정하고 1280×720·큰 글자 상태에서 재측정한다. 전체 레이아웃 변경은 이번 복구 범위에서 수행하지 않았다.
3. **13번 8→11 / 17번 측정 불가:** 실물 iPad/Android의 가로·세로·쓸기·핀치·WebGL 대안과 실제 첫 로딩·교실 네트워크를 측정한다. 11점은 이 조건을 충족한 뒤 다시 판단한다.

실제 학생의 난이도·흥미·설명, 초등 과학 성취기준 원문 대조, 오프라인·동시 접속, 공개 URL 검증은 각각 남은 확인 범위다. 공개 배포를 진행하기 전에 제작자/교사가 확인해야 하며 일정은 정하지 않았다.
