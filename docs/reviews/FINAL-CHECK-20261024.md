판단→조작→결과→다시 바꿔 볼 이유가 있는지 단계별로 확인했다. 그림·점수·캐릭터를 걷어내도 특징 비교·예상 검증·환경 배치·설계 시험이 남는다. 시간 제한·목숨 차감·오답 초기화로 긴장을 대신하지 않는다.

| 스테이지 | 긴장·판단 장치 | 게임 조작 | 즉시 결과·보상 | 다시 해 볼 이유·약점 |
|---|---|---|---|---|
| 1 관찰과 분류 | 모양과 가장자리 중 어떤 기준인지, 기준 변경 시 배치 판단 | 돌리기·확대·잎 옮기기·두 기준 분류·근거 연결 | 불일치 수·관찰 기록·온실 복구·렌즈·빛씨앗 | 다른 잎/기준으로 재분류. 완주 후 새 목표 폭은 좁음 △ |
| 2 계절과 생활 | 겨울에 안 보이는 식물은 죽었는지 예상 | 시간 이동·땅속 열기·사진 남기기·겨울과 다음 봄 연결 | 예상과 확인 결과·두 식물 기록·꽃돔·수첩·꽃길 | 식물별 살아남는 부분 비교. 같은 두 증거를 다시 잇는 이유는 약함 △ |
| 3 환경과 특징 | 공기가 있는/없는 모형 결과, 방울이 뜻하는 것 판단 | 같은 물에서 모형 비교·잎자루 자르기/누르기·환경 연결 | 공기 방울·예상 대비·물길 복구·물병 | 알로에 물 저장과 다른 특징·환경 비교 ○ |
| 4 정원 만들기 | 내가 만든 땅에서 이 식물이 살기 좋은지 판단 | 물가·풀밭·건조 구역 칠하기·지우기·되돌리기·세 식물 심기 | 지형과 식물 즉시 변화·배치 까닭·정원 복구·도구 | 다른 모양·위치로 다시 설계하고 조건 확인 ○ |
| 5 발명과 개선 | 연잎 겉면만으로 열린 입구까지 막을 수 있는지 예상 | 표면 물방울·확대·겉면만 변경/같은 비 시험·덮개만 변경/비교·설명 수정 | 겉면/수첩 결과의 차이·각 부품 근거·공방·탐험 가방 | 네 조합에서 두 역할을 분리 검증하고 비옷·신발에 적용 ○ |

가장 약한 재플레이 구간은 2단계 사진 연결이다. 첫 판단의 학습 가치는 있지만 완주 뒤 같은 사진을 다시 잇는 목표는 적다. 다른 근거를 찾아 설명을 바꾸는 확장이나 학생의 자발적 재방문 관찰이 후속 과제다. 신규 타이머·반복 클릭 배지는 추가하지 않았다.

## 디자인·아이스크림 설정 확인

공통 틀은 배경 전체와 왼쪽 홈·이전/오른쪽 소리·설정 네 아이콘이다. 메인의 리피와 초대 문구를 중앙으로 키우고, 정원·가방은 관찰과 결과가 함께 보이도록 패널을 재배치했다. 도구 팝업·연구노트·엔딩은 기본 상태에서 한 화면을 우선하고, 도움말·추가 설명은 필요할 때 펼친다. 모바일 세로와 펼친 기록은 필요한 내부 스크롤을 허용한다.

설정은 배경 음악/효과음 분리·BGM 음량 → 동기 영상/완료 후 엔딩 → 앱 정보 → 학생 → 교사(성취기준·시연) → 저작권(출처) → 확인을 거치는 기록 초기화/닫기 순서다. 소리 선택은 초기화 뒤 남고 교사 해금은 학생의 완료 기록과 분리한다. 학년·수업 시간·개인 메일·앱 밖 링크를 학생 설정에 넣지 않는다.


UI 측정·자동 탐지의 예외·대표 화면 재확인 상세는 [LAYOUT-SUMMARY.md](final-20261024/LAYOUT-SUMMARY.md)와 E2에 모았다. 모든 인접 터치 간격·모든 장면/상태 대비의 정량 전수 측정, 보조기기 전수 감사·실물 회전 검증은 수행하지 않았다. 정적 선언과 대표 화면 검사를 전수·실기기 통과로 확대하지 않는다.
