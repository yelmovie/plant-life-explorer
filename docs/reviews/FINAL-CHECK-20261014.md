## 직접 수행한 기능 검증

최종 자동 검사: JavaScript 9파일 문법 통과, 로직 테스트 12/12 통과. 납품 빌드 28파일·3,679,102 bytes. dist 전용 서버에서 28개 응답이 파일 원본과 바이트 일치하고 WebP MIME이 정상임을 확인했다. 숨김/상위경로 요청 403, 없는 파일 404. 납품 빌드에서도 소개→지도→관찰 진입 및 메인 이미지 로드·콘솔 오류 0건을 확인했다.

검증 환경: Codex 내장 Chromium, 새 로컬 origin `127.0.0.1:4321`. 기존 사용자 origin의 진행 기록을 초기화하지 않았다.

1. 일반 모드에서 소개 → 미션 1만 열린 지도 확인. 1.2배 미만 관찰 안내 확인 후 세 표본을 확대해 모양·가장자리 6개 기록, 분류 완료.
2. 벚나무·씀바귀의 봄/여름/겨울 6개 기록, 땅속 관찰, 벚나무 겨울/다음 봄 증거 연결.
3. 잎자루 자르기 → 확대 → 물속 → 누르기 → 기록, 알로에 비교. 식물 3종의 환경과 근거 연결.
4. 물가·풀밭·건조 구역을 각 6칸 그리기, 식물 3종 배치·근거 확인. 지형과 식물이 최종 정원에 유지됨.
5. 기본 천/열린 입구 시험은 두 기능 미충족. 연잎 표면/덮개로 바꾸면 이전 결과가 현재 가방에 표시되지 않고 재시험 안내가 나옴. 재시험 후 두 기능 통과.
6. 보고서 3/5 연결 후 새로고침 → 3/5 유지. 5/5 연결 후 새 표본 분류·선인장 환경·정원·발명 기능을 확인하여 인증서 도달.
7. 시험 중 홈 이동 → 다시 시험 화면 진입 시 기존 시험 2개 유지. 중단한 시험이 뒤늦게 기록되지 않음.
8. 이미지 확대 모달, 교사용 미리보기, 큰 글자 토글 확인. 직접 수행한 전체 흐름에서 콘솔 error/warn 0건.

## 반응형·시각 증거

`viewport-results.json`에 DOM 기반 검사 79건을 보관했다. 모든 검사에서 문서 가로 넘침, 로드 실패 이미지, 이미지 대체 문구 0건이다. 이것은 전체 UI 접근성 인증이나 실제 터치 검증을 의미하지 않는다.
