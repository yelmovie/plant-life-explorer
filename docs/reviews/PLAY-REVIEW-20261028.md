# 초록정원 활동 흐름 점검 · 2026-10-28

목표는 초등 학습자가 태블릿에서 관찰하고 조작하는 동안 식물 개념을 익히는 것이다. 이미 한 관찰·시험은 다음 활동의 증거로 이어 쓰고, 새로운 상황에 적용하는 행동은 남겼다. 기존 미커밋 변경은 보존했으며, 이번 작업에서 공개 배포는 하지 않았다.

## 5개 미션의 활동 흐름

| 미션 | 점검한 중복·불편 | 개선 후 필수 활동과 남긴 배움 |
|---|---|---|
| 1. 관찰과 분류 | 현장 두 기준 분류 뒤 새 잎 3종의 특징 6개를 다시 문답하고 근거를 다시 선택했다. 한 기준만 필요해도 두 기준을 마치라는 안내가 남아 있었다. | 돋보기로 단서를 찾고 세 잎을 두 기준으로 분류한다. 후속에서는 새 잎 세 장에 선택한 기준 하나를 적용하면 배치 자체가 기록이 된다. 별도 특징 문답·근거 확인은 생략하며, 다른 기준은 더 해 보기로 남긴다. 바구니 탭도 스와이프와 같은 결과를 만든다. |
| 2. 계절과 생활 | 겨울과 봄을 연결하고 새싹 위치까지 찾은 뒤 같은 결론을 객관식으로 다시 답했다. | 두 식물의 첫 예상, 겨울에 살아 있던 부분 연결, 시간 다이얼, 새로 자란 곳 찾기는 유지한다. 실제 현장 관찰과 설명을 사진·노트로 이어 쓰고 중복 질문은 발견 요약으로 바꿨다. 겨울눈 추가 탐색은 선택 활동이다. |
| 3. 환경과 특징 | 공기 모형을 넣은 뒤 일정 시간 길게 눌러야 터치 경로의 시험이 기록됐다. 사는 곳을 고른 뒤 ‘특징’과 ‘도움’을 따로 답했다. | 두 모형을 각각 넣으면 뜨고 가라앉는 결과가 즉시 기록된다. 길게 눌렀다 놓기는 선택 놀이로 남겼다. 단면의 공기 공간과 뜨는 결과를 연결하고, 세 식물은 ‘사는 곳 + 특징이 주는 도움’ 두 선택으로 연결한다. 이미 본 잎자루 실험을 다시 수행하지 않는다. |
| 4. 정원 만들기 | 현장에서 만든 정원·앞 미션의 환경 근거를 다시 만들거나 답할 필요가 있었다. 같은 자리를 다시 누르기만 해도 비 시험 결과가 지워졌다. | 비가 고이고 스며들고 빠지는 곳을 살펴보고 세 식물을 배치한 뒤 비로 확인한다. 현장 정원과 앞서 고른 까닭을 이어 쓰는 흐름을 유지·검증했다. 곧바로 복구할 수 있으며 더 꾸미기는 선택이다. 실제 배치가 바뀔 때만 재시험을 요구한다. |
| 5. 발명과 개선 | 한 부품 비교를 마쳐도 현장 단계에서 완성 가방을 요구해 추가 시험을 강제했다. 같은 시험이 노트에 두 번 나타났다. | 부품 하나만 다른 두 시험과 바뀐 부품 찾기를 현장 증거로 인정한다. 뒤에서는 아직 확인하지 않은 부품의 역할만 더 비교한다. 최종 완료에는 연잎 겉면·닫힌 덮개와 두 역할의 비교 증거가 모두 필요하다. 이미 시험한 설계는 재시험 없이 기록을 선택하고, 노트에는 이어받은 시험을 한 번만 표시한다. |

필수 활동을 줄여도 답하지 않은 특징을 정답으로 만들지는 않는다. 잎의 세부 모양 문답과 실제 분류 행동은 별도 기록으로 남기며, 최초 예상·오답·수정·힌트 사용도 보존한다.

## 성취기준과 연결

아래 문구는 프로젝트의 `src/settings-content.js`에 있는 2022 개정 과학과 교육과정 연결 기준을 그대로 사용했다.

- **[4과03-01]** “여러 가지 식물을 관찰하여 특징에 따라 식물을 분류할 수 있다.” 미션 1의 관찰, 두 기준 분류, 새 잎 적용으로 연결한다.
- **[4과03-02]** “다양한 환경에 서식하는 식물을 조사하여 식물의 생김새와 생활 방식이 환경과 관련되어 있음을 설명할 수 있다.” 미션 3의 모형 비교·환경 연결과 미션 4의 식물 배치·근거 적용으로 연결한다. 미션 2의 계절 변화는 살아 있는 부분과 생장에 관한 보조 관찰이다.
- **[4과03-03]** “식물의 특징을 이용하여 일상생활에서 활용할 수 있는 생활용품을 설계하여 협력적으로 소통할 수 있다.” 미션 5에서 연잎의 특징을 가방 설계에 적용하고 부품별 시험으로 개선한다. 보고 화면의 공유 안내를 제공하지만, ‘나중에 공유’로도 끝낼 수 있으므로 앱 완주만으로 실제 협력적 소통까지 달성했다고 판정하지 않는다.

## 함께 고친 기능 문제

- 단풍나무만 필수 관찰한 뒤 소나무·동백나무를 분류하면 오답과 수정이 학습 기록에서 빠지던 조건을 수정했다. 새 잎 배치도 기준·표본별 응답으로 기록한다.
- 잘못된 식물·기준·답 입력과 필수 관찰 전 동작은 분류 응답을 만들지 않는다.
- 부력 실험의 터치와 키보드 완료 조건을 맞췄다. 손을 오래 대지 않아도 시험 기록이 남고 장면을 옮겨도 저장된 관찰이 유지된다.
- 바구니 연속 탭은 카드를 한 번만 처리한다. 잎 카드·가방 빗방울의 진행 중 애니메이션은 화면을 떠나면 정리하여 뒤늦은 상태 변경을 막는다.
- 같은 정원 상태를 다시 선택해도 시험 증거가 지워지지 않는다.
- 완료 조건에 맞춰 분류·계절·정원 안내를 정리했다. 보상과 연구 노트가 현장 관찰·분류 기록을 포함하고, 하지 않은 잎자루 누르기나 없는 가방 부품을 수행했다고 표시하지 않도록 수정했다.
