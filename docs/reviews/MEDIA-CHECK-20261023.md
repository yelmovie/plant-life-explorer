# 인트로·아웃트로 적용 확인 — 2026-10-23

## 적용

- 기존 글 팝업을 전체 화면 영상으로 교체했다. 첫 연구 시작 → 인트로 → 지도, 완료/엔딩 다시 보기 → 아웃트로 → 탐구 기록으로 연결한다.
- 원본 HEVC 1080p 29.82MB/31.67MB는 루트에 보관하고, 웹용 H.264 Main/yuv420p 720p·AAC·faststart 사본을 사용한다.
- `assets/videos/intro.mp4`: 23.545초, 3,971,151바이트. `outro.mp4`: 25.472초, 6,320,654바이트.
- 장면별 한국어 이야기 자막은 `src/story-data.js`에 있다. 자막·소리 전환, 일시 정지, 구간 이동, 건너뛰기, 설정 다시 보기를 제공한다.
- 영상은 초기 오프라인 캐시에 넣지 않는다. 실패 안내와 재생 버튼, 다음 화면으로 넘어가는 버튼을 제공한다.

## 실제 브라우저 확인

Codex 앱 브라우저, 1395×892에서 확인했다. 일반 시작 흐름은 localhost 주소에서 확인했다.

| 항목 | 결과 |
|---|---|
| 인트로 재생 | PASS — 영상 크기 1280×720, readyState 4, 시간이 진행됨 |
| 시작 팝업 제거 | PASS — dialog 닫힘, 영상이 뷰포트 전체를 차지함 |
| 일반 시작 버튼·건너뛰기 | PASS — 영상 진입 후 지도에 연결됨 |
| 인트로 다시 보기 종료 | PASS — 재생 종료 후 설정으로 복귀 |
| 아웃트로 재생·구간 이동 | PASS — 마지막 구간으로 이동 후 자연 종료되어 탐구 기록 표시 |
| 일시 정지·소리·자막 | PASS — 실제 조작과 표시 상태 확인, 소리 설정 원상 복구 |
| 자막 배치 | PASS — 조작부보다 위에 있고 가로 넘침 없음 |
| 콘솔 경고·오류 | PASS — 확인한 탭에서 수집된 경고·오류 없음 |
| 물리적 스피커 청취·실물 태블릿 | NOT TESTED |
| 학교망·오프라인 실패·자동재생 차단 강제 재현 | NOT TESTED — 실패 처리는 구현했으나 이 조건을 강제 재현하지 않음 |

첫 재생의 짧은 로딩 안내 이후 재생과 자막을 확인했다. 전 구간의 정량적 버퍼링 계측은 수행하지 않았다. 이 앱에는 게임 BGM 트랙이 없으며, 영상 진입 시 기존 UI 효과음을 정지한다.
