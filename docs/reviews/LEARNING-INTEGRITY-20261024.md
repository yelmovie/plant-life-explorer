### 새 기록으로 실제 UI 완주

`tests/learning-journey.browser.mjs`는 격리한 Chrome 새 프로필에서 진도·정답을 주입하지 않고 화면의 버튼, 터치 탭과 키보드로 진행했다. WebGL을 끈 그림 모드에서 **5개 현장 임무 → 10개 본 탐구 → 최종 선인장 적용 문제 → 엔딩 → 연구노트**를 완주했다.

- 매 장소 완료 뒤 새로고침하여 저장 내용이 그대로 남는지 확인했다.
- 주머니만 열림→닫힘으로 바꾸었을 때 그림/접근성 설명/주머니 젖음이 함께 바뀌고, 공책 결과는 동일했다.

## 한계와 미검증

- **실물 iPad Safari·Android Chrome의 터치·회전은 미검증**이다. 위 결과는 Windows Chrome 자동화의 뷰포트·터치 에뮬레이션이다.
- WebGL은 소프트웨어 렌더러로 확인했다. 실물 태블릿 GPU 성능·학교망·실제 학생 수업은 검증하지 않았다.
- Web Locks를 지원하지 않거나 저장소 접근이 금지된 브라우저는 안전하지 않은 덮어쓰기를 하지 않고 지속 경고를 표시한다. 파일 보관은 제공하지만 앱 내 JSON 가져오기는 제공하지 않는다.
- 저장 기록이 없는 이전 사용자의 첫 응답·힌트는 추정 복원하지 않는다. 완료는 유지하고 해당 과정은 ‘확인되지 않음’으로 남긴다.
- 초기 검증에서 작은 가방 영역과 테스트 선택자 문제가 발견되어 수정·재검증했다. 병렬 렌더링 작업 중 첫 화면 타임아웃이 한 차례 발생하여 단독 완주를 다시 실행했고, 위 결과는 성공한 최종 실행이다.
