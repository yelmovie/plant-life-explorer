## 경로·미사용·용량

- 카탈로그 키 56개에 해당하는 WebP 파일이 모두 존재한다. 썸네일 5개도 존재한다.
- 캐릭터 3종, 계절 관찰 그림 2종, 표정 12종, 도장 일부와 썸네일은 코드가 이름을 조합한다. 문자 그대로의 파일명 검색이 0건이어도 미사용으로 판단하지 않았다.
- 실행용 WebP·GLB·서브셋 WOFF2 중 1,000,000 B를 넘는 단일 파일은 없다. 대용량 PNG 원본은 `scripts/build.mjs`가 배포에서 제외한다.
- 배경 `greenhouse_studio_v1`, `plant_lab_background`는 CSS 참조가 남아 있다. 새 활동 배경이 덮어쓰더라도 대체 경로를 확인하지 않고 이동하지 않는다.
- 기존 `_unused/DELETE-CANDIDATES.md`를 현재 보관 경로에 맞췄다. 원본·과거 결과물의 보관 결정은 정적 참조 검색과 별개다.
- 이번 문서 작업에서는 브라우저 네트워크 404·모든 화면의 이미지 로딩·학교망 성능을 재측정하지 않았다. 빌드의 경로 검사와 브라우저 검증 결과는 최종점검 본문에 별도로 기록한다.

## 그림 품질·재사용

- 기존 리피, 관찰대 배경, 완료 도장을 직접 열어 확인했다. 캐릭터의 둥근 입체감·세이지색 온실·새싹 도장이라는 시각 언어가 이어지고 활동별 배경 10장과 표정 12장이 이미 있다.
- 현재 UI 개선에 꼭 필요한 그림이 부족하다는 근거는 없다. 공통 조작은 SVG를 쓰고 기존 배경·캐릭터·보상 그림을 재사용한다.
- 계절 관찰 그림은 네 구역을 CSS로 보여 주는 의도적인 아틀라스다. 전체 4칸 시트를 일반 장식 이미지로 노출하거나 새 UI를 그림에 합성하지 않는다.
- 새 이미지 생성은 하지 않았다. 조작 아이콘과 장식 도장의 제작 기준은 `docs/icon-prompts.md`에 구분해 기록했다.
