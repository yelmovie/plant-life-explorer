# 초록정원 학생 사용성과 교육과정 재검토

검토일: 2026-10-16. 대상: 현재 0.3의 전체 화면 구성·문구·판정 코드와 태블릿 탐구 경험 설계. 판단: **방향은 맞지만, 학생용 표현·반복 조작·필수 탐구량·협력적 소통을 보완해야 한다.** 새 설계를 그대로 구현하는 상태는 수용하지 않는다.

현재 화면은 이전 브라우저 점검과 이번 소스 전수 확인을 함께 사용했다. 새 설계의 사용성 평가는 설계 검토이며 실제 초등학생 사용성 시험을 대신하지 않는다. 아래 우선순위는 구현 순서이지 실측된 결함 빈도가 아니다.

## 1. 교육과정 대조

2026년 초등 3학년 검토 기준은 2022 개정 과학과 교육과정이다. 초등 3·4학년 적용 시작일은 2025년 3월 1일이다. 근거: [교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=), 부칙.

성취기준은 아래처럼 요약했다. 공식 문구는 [충청북도교육청 2025 초등학교 교육과정](https://pain.cbe.go.kr/upload/dept-19/na/bbs_1437/2025/01/42D2EF47-B7BF-7348-32ED-418D79977B1A.pdf)의 인쇄 92쪽, PDF 92번째 페이지에서 대조했다. 해당 자료 후반에는 2015 기준도 함께 있으므로 2022 부분을 기준으로 삼았다.

| 기준 | 핵심 요구 요약 | 현재·초안 평가 | 개편 기준 |
|---|---|---|---|
| [4과03-01] | 식물을 관찰하고 특징을 기준으로 분류 | 잎 관찰·분류는 맞음. 두 기준을 모두 강제하면 학생이 기준을 고르는 의미가 약함 | 잎 3종 관찰 → 기준 하나 선택 → 분류와 이유 확인. 두 번째 기준은 더 해보기 |
| [4과03-02] | 여러 환경의 식물 생김새·생활 방식과 환경의 관련성을 설명 | 환경 답 맞히기는 있으나 조사보다 선택 문항 비중이 큼 | 환경 그림에서 물·땅의 조건을 살피고 식물의 관찰 카드로 설명. 장소 이름만 맞혀서는 완료하지 않음 |
| [4과03-03] | 식물의 특징을 이용한 생활용품 설계와 협력적 소통 | 설계·시험은 있음. 친구와 설명·질문·의견 교환 과정은 빠짐 | 설계 이유 설명 → 친구의 질문·의견 듣기 → 반영 또는 유지 이유 말하기를 수업 활동으로 연결 |

해설과 범위는 [교육부 별책 9 고시 원문 공개 사본](https://padlet-uploads.storage.googleapis.com/959036363/92d863a882003cbf6cf9181b89a29c01/2022___9__________.pdf)의 인쇄 14~15쪽(PDF 20~21번째 페이지)에서 확인했다. 잎의 외형에 따른 관찰·분류가 중심이며, 전문적인 생물 분류 체계와 적응 개념을 도입하지 않는다. 기관의 구조·기능을 상세하게 가르치는 방향은 이 단원의 중심이 아니다.

계절 변화는 연결 탐구로 활용할 수 있다. 그러나 벚나무와 씀바귀의 겨울·봄만 관찰하는 활동으로 한살이 유형의 다양성을 다루는 [4과04-03] 전체를 충족했다고 평가하면 안 된다. 기본 목표는 이 앱에서 제시한 두 시점의 모습을 비교하는 데 한정한다.

### 교육 내용 수정 결정

- 계절 활동은 기존 이야기 속에 남기되 교사용 지도안에 ‘연결 탐구’로 표시한다. 세 핵심 성취기준과 동일한 필수 평가량을 배정하지 않는다.
- 단면과 기포는 생김새·사는 곳의 관계를 이해하는 보조 관찰이다. 조직명, 세포, 부력 계산, 진화·적응을 외우게 하지 않는다.
- ‘물을 저장하려고 두꺼워졌어요’ 같은 목적론적 표현을 쓰지 않는다. 학생 문장은 ‘두꺼운 잎 안에 물을 담고 있어요’ 수준으로 쓴다.
- 가방의 덮개는 입구 보호를 위한 별도 해결책이다. 이를 연잎에서 가져온 특징인 것처럼 설명하지 않는다.
- 앱 모형에서 덮개가 수첩을 지키는 결과를 모든 실제 천 가방의 방수 성능으로 일반화하지 않는다. 시험 장면에 ‘이 가방 모형에서 비교해요’를 짧게 표시하고 교사용 설명에서 범위를 밝힌다.
- 화면 관찰은 실제 잎 관찰과 함께 사용할 수 있는 보조 도구다. 주변 잎을 관찰하는 수업을 디지털 그림만으로 모두 대체했다고 표현하지 않는다.
- 학생의 버튼 클릭 기록은 성취기준 도달의 충분한 증거가 아니다. 관찰 내용·설명·교사의 대화 관찰을 함께 사용한다.

## 2. 학생 부담이 큰 부분

| 우선순위 | 발견한 문제 | 근거 | 수정 방향 |
|---|---|---|---|
| 높음 | 할 일보다 화면 장식·안내가 먼저 보임 | 기존 1280×800에서 실험 도구와 비 뿌리기 버튼이 첫 화면 아래로 내려감 | 제목+지시 1개, 대상+도구+결과가 함께 보이는 셸 |
| 높음 | 새로운 상호작용마다 또 다른 조작을 배워야 함 | 새 설계에 돋보기·핀치·드래그·절단선·긴 누르기·겹치기·증거 이동이 누적됨 | 기본은 ‘고르고 누르기’. 제스처는 선택적 지름길. 한 장의 새 필수 조작은 한 가지 이내 |

| 중간 | ‘이전’의 뜻이 모호 | 헤더 이전 버튼은 실제 탐색 이력이 아닌 PAGE_ROUTES의 앞 화면으로 이동 | 아이콘 단독 대신 ‘앞 활동’ 또는 ‘지도’로 목적지를 명시 |
| 중간 | 마지막에 다시 확인만 반복 | 보고서 5장 각각 연결 + 시운전 4개 확인 | 보고서는 자동 묶기. 새 상황 적용 1개와 설명 나누기에 집중 |

## 3. 전체 화면별 학생용 기준

| 화면 | 첫눈에 보여 줄 것 | 첫 행동 또는 대표 문구 | 줄이거나 없앨 것 |
|---|---|---|---|
| 메인 | 제목, 대표 장면, 시작/이어하기 1개 | ‘탐구 시작’ | 영어 장식 문구·반복 슬로건·동등한 여러 시작 버튼 |
| 지도 | 지금 갈 장소 1개와 진행 | ‘잎을 살펴보러 가요’ | 현재 장소를 다시 선택해야만 시작하는 절차, 상세 활동 목록 상시 노출 |
| 1 잎 관찰 | 큰 잎과 조사할 부위 | ‘잎의 가장자리를 눌러 봐.’ | 배율 조건, 회전 필수, 캡처→저장→확인 중복 |
| 2 분류 | 선택한 질문과 두 모둠 | ‘잎을 고르고 놓을 곳을 눌러 봐.’ | 필수 두 판 동시 작성, ‘그래요’만 있고 질문이 멀리 있는 배치 |
| 3 계절 | 같은 식물과 시간 막대 | ‘겨울에서 다음 봄으로 움직여 봐.’ | 6개 기록 체크리스트, 땅속 조작과 시간 조작 동시 지시 |
| 4 계절 비교 | 겨울·봄 두 사진 | ‘봄에 달라진 곳을 찾아봐.’ | 카드 찾기·옮기기·부위 표시·문장 완성을 모두 별도 단계로 요구 |
| 5 잎자루 | 큰 표본, 현재 도구 1개 | ‘물속에 놓고 눌러 봐.’ | 처음부터 도구 5개 나열, 정확한 선 따라 자르기, 작은 기포 누르기 |
| 6 사는 곳 | 환경 그림과 식물 | ‘어느 곳에 놓을까?’ 다음에 ‘어떤 모습을 보고 골랐어?’ | 환경 선택과 근거 선택을 한꺼번에 지시, 긴 드롭다운 |
| 7 정원 | 바로 수정할 수 있는 정원 | ‘식물이 살 자리를 꾸며 봐.’ | 빈 화면과 칸 수 숙제, 완료를 막는 장식 선택 |
| 8 식물 심기 | 선택 식물·놓을 자리·다시 옮기기 | ‘식물을 고르고 자리를 눌러 봐.’ | 정답 문장 옆 ‘근거 확인’ 버튼을 누르기만 하는 절차 |
| 9 가방 만들기 | 연잎의 물방울과 겉면 선택 | ‘연잎처럼 물방울이 굴러가게 해 볼까?’ | 예상을 정답으로 채점, ‘연잎 코팅’ 용어만 제시 |
| 10 가방 시험 | 시험 버튼·가방·수첩 | ‘비를 뿌려 봐.’ → ‘하나만 바꿔 볼까?’ | 비교 쌍 고정·조건 ID 등 내부 개념, 처음부터 세 시험 의무 |
| 발견 모음 | 내가 만든 결과와 설명 카드 | ‘어떤 발견을 소개할까?’ | 카드 5장을 일일이 제출하는 반복 |
| 마지막 탐구 | 새 상황 1개 | ‘새 잎도 나눌 수 있을까?’ | 이미 판정한 정원·가방을 다시 확인만 하는 버튼 |
| 엔딩 | 내 정원·내 가방·대표 발견 | ‘내 정원 보기’ | 시험 횟수 강조를 성취 점수처럼 사용 |
| 연구 노트 | 최근 발견과 활동별 기록 | 기록 선택 시 해당 그림 확대 | 새 학습을 열기 위해 반드시 탐색해야 하는 복잡한 서랍 |
| 설정·교사 안내 | 소리·큰 글자·도움말 | 학생 조작과 교사 설정 분리 | 학생 활동 중 관리자 우회 ‘다음’과 실제 ‘다음’ 병치 |
| 보상 | 바뀐 시설과 발견 1개 | ‘다음 장소’ 1개 강조 | 보상 이유·증거 요약·진행·다음 예고를 모두 장문으로 반복 |

학생에게 의미 있는 용어인 잎자루·관찰·분류는 모두 없애지 않는다. 잎자루는 해당 부위를 가리켜 소개하고, 분류는 ‘특징이 비슷한 것끼리 나누기’와 함께 처음 한 번 설명한다. 이후에는 같은 용어를 일관되게 사용한다.

### 용어와 문장 교체 예

| 기존/초안 | 학생 화면 |
|---|---|
| 식물 표본 스캔 | 잎을 살펴봐요 |
| 계절 관찰 타임랩 | 계절을 바꿔 봐요 |
| 생활 증거 분석실 | 겨울과 봄을 비교해요 |
| 환경 실험 챔버 | 잎자루를 살펴봐요 |
| 서식지 판정실 | 식물이 사는 곳 |
| 지형 설계 | 정원 꾸미기 |
| 배치 근거 확인 | 이 자리를 고른 까닭 |
| 단면 확대 | 자른 면 크게 보기 |
| 연잎 코팅 | 연잎을 닮은 겉면 |
| 오염 제거 / 입구 보호 | 먼지가 떨어져요 / 입구로 비가 들어오지 않아요 |
| 연구 기록이 준비됐어 | 잎 세 가지를 살펴봤어. 다음으로 가자. |
| 직접 탐구하고 연구 기록을 모아 줘 | 은행나무 잎의 가장자리를 더 살펴봐. |

제목은 간단한 명사형 또는 ‘~해요’, 캐릭터 안내는 기존의 친근한 말투, 학생의 설명 문장 틀은 ‘~했어요’로 역할별 일관성을 유지한다. 사용자를 향한 어시스턴트 말투 규칙을 앱 콘텐츠 전체에 덮어쓰지 않는다.

## 4. 기본 활동과 더 해보기

| 활동 | 기본에서 요구 | 더 해보기 |
|---|---|---|
| 잎 | 3종의 모양·가장자리 관찰, 특징 선택과 함께 자동 기록 | 자유 확대·회전·겹쳐 비교 |
| 분류 | 학생이 고른 기준 1개로 분류하고 특징으로 설명 | 다른 기준으로 재분류하여 이전 판과 비교 |
| 계절 | 선택한 식물의 겨울·다음 봄 2장과 차이 1개 | 다른 식물·여름·가을·땅속 비교 |
| 잎자루 | 큰 부위 관찰과 물속 누르기, 본 현상 하나 연결 | 상세 단면·알로에 비교 |
| 사는 곳 | 세 대표 식물과 환경을 연결하고 그림 근거 확인 | 다른 환경·새 식물 사례 |
| 정원 | 기본 정원을 수정하고 세 식물 자리와 까닭 연결 | 빈 정원에서 자유 설계 |
| 발명 | 식물 특징이 쓰인 설계·시험, 한 부품 비교 1쌍, 그 결과 설명 | 두 부품의 효과를 각각 비교, 네 조합 탐색 |

기본 활동 완료와 모든 확장 활동 완료를 같은 것으로 표시하지 않는다. 확장 기록을 완료·빛씨앗·다음 미션의 숨은 필수 조건으로 삼지 않는다. 두 기능을 모두 설명하려는 학생에게는 두 비교 쌍이 유용하지만 이를 모든 학생의 진입 장벽으로 삼지 않는다.

## 5. 협력적 소통을 추가하는 방법

서버나 온라인 공유 없이 같은 태블릿을 보며 말하는 수업 활동으로 시작한다.

1. 앱이 현재 가방·시험 결과를 한 장의 ‘내 가방 소개’로 묶는다.
2. 학생이 ‘연잎의 ○○ 특징을 가방의 ○○에 썼어요’ 틀로 실제 설계를 설명한다. 답 문장을 처음부터 완성해서 보여 주지 않는다.
3. 옆 친구는 ‘이건 왜 골랐어?’, ‘이 부분을 바꾸면 어떨까?’ 중 질문을 골라 말한다. 선택지는 대화를 돕는 예시이며 다른 질문도 가능하다.
4. 설계자는 의견을 듣고 수정해 시험하거나, 유지한 까닭을 설명한다. 무조건 수정하도록 요구하지 않는다.

‘이야기를 나눴어요’는 학생의 자기 확인이며 자동 성취 판정이 아니다. 혼자 사용하는 경우 ‘나중에 이야기하기’를 선택해 개인 탐구 완료는 허용하고 소통 기록은 미확인으로 둔다. 개인 탐구 완료와 [4과03-03]의 협력적 소통 확인을 교사용 요약에서 구분한다. 이름·음성·친구 개인정보를 저장하지 않는다.

## 6. 학생 화면 수용 기준

- 첫 화면에서 대상, 지금 할 일 한 문장, 주요 행동 하나가 보인다.
- 선택지가 여러 개 있어도 강조된 ‘실행’은 하나다. 다음 활동 버튼은 조건 충족 후 강조한다.
- 필수 지시를 제목·캐릭터·수첩·토스트에 중복 표시하지 않는다.
- 상태 안내는 관찰 대상 옆에서 유지한다. 사라지는 토스트만 읽어야 진행할 수 없게 한다.
- 숨은 드래그·핀치·길게 누르기를 알아야만 통과할 수 없다.
- 이전으로 가거나 관찰을 다시 열어도 이미 남긴 기록을 잃지 않는다.
- 도움말은 현재 행동만 짧게 보여 주며 전체 사용법을 먼저 외우게 하지 않는다.
- 사용성 시험에서는 교사 설명 없이 첫 행동을 찾는지, 막힌 이유를 이해하는지, 수정 후 결과를 설명하는지 관찰한다. 첫 행동을 찾는 10초는 설계 평가용 목표이며 이미 검증된 수치가 아니다.
- 정확한 학년·학기 배치는 사용하는 교과서 판본의 단원 구성과 마지막으로 대조한다. 국가 성취기준의 학년군 적합성과 특정 교과서 순서 적합성을 구분한다.

## 7. 반영 상태

본 재검토를 태블릿 설계서의 기본/확장 구분·완료 조건·소통 활동·화면 정책에 반영한다. 구현 계획은 `../IMPLEMENTATION-PLAN-20261016.md`에서 단계별 산출물과 검증을 관리한다. 현재 앱 코드는 아직 새 설계를 구현하지 않았으므로 이 문서의 수정 방향을 ‘해결 완료’로 기록하지 않는다.
