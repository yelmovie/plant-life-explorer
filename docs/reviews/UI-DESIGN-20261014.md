# UI 디자인 개선 — 2026-10-14

## 범위와 기준

- 수정 파일: `src/style.css`.
- 기존 forest/cream 팔레트, 시스템 한글 글꼴, 2D 학습 화면과 2.5D 지도 방향 유지.
- 디자인 스킬과 education-ui-rules 적용. 프로젝트의 기존 브랜드가 기본 교육 파랑 토큰보다 우선.
- 게임 로직·저장 키·학습 데이터·배포 설정은 이 디자인 작업에서 수정하지 않음.

## 적용

- 본문·선택 버튼은 기본 16px, 핵심 지시문 18px, 보조 메타 12~14px로 개선. 기존 모바일의 7~11px 축소 규칙 제거.
- 큰 글자 모드에서 주요 본문 19px, 버튼 18px, 지시문 21~22px.
- 연구 수첩 폭 300px / 중간 화면 272px. 850px 이하 2열, 560px 이하 1열.
- 본문이 늘어도 지시문 패널이 자동으로 높아지도록 변경. 하단 진행 바에서 좁은 화면은 상태와 동작을 두 줄로 배치.
- 모바일 홈 미션 목록 2열, 좁은 지도에서는 핀 번호로 선택하고 미션 상세 카드에서 이름과 설명 확인.
- 버튼과 정원 셀 48px 터치 기준. 정원은 매우 좁은 화면에서 프레임 내부 스크롤로 조작 크기 유지.
- 약한 회색 초록 본문을 더 진한 muted 토큰으로 통합. 포커스 외곽선 대비와 선택 테두리 강화.
- 토스트 상단 배치. 600px 이하 높이의 가로 화면에서는 헤더/진행 바 고정을 풀어 본문 가림 완화.
- 기존 reduced-motion 대응 유지, 안전 영역 하단 여백, 다이얼로그 버튼 줄바꿈, 큰 글자 부품 선택 1열 적용.
- 기존 규칙을 직접 수정하고 추가 규칙은 레이아웃 안전장치와 접근성 대응에 제한.

## 검증 범위

- 정적 검증: CSS 중괄호 805쌍 일치, 12px 미만 명시적 글꼴 크기 없음.
- 대비 실측: 본문/종이 11.51:1, 보조본문/수첩 5.40:1, 주버튼 9.14:1, 포커스/크림 4.64:1. 핵심 텍스트 4.5:1 기준 충족(전체 화면의 모든 색 조합 통과를 의미하지 않음).
- 브라우저 실측: 통합 담당자가 생성 이미지 반영 후 1280×800, 1024×768, 1920×1080, 모바일 375/768/915px 폭에서 진행. 이 문서 작성 시점에는 NOT CHECKED.
- 게임 기능 검증/학습 흐름/저장 복원은 통합 테스트 결과를 별도로 따른다.
- 새 이미지 표시 클래스는 통합 담당자 소유이며 이 수정의 검증 범위에 포함하지 않는다.
