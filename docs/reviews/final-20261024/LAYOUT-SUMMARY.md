# 최종 화면 검증 요약 · 2026-10-24

## 범위와 판정

`layout.json`은 20개 화면을 5개 가로 화면 크기에서 렌더한 100건의 측정이다. 메인, 활동 1~10, 현장 1~5, 연구노트, 마지막 적용, 엔딩, 지도를 포함한다. 화면 이름의 활동 번호는 사용자에게 보이는 1부터 시작하는 번호이며 소스의 `activity-0`과 한 칸 차이가 있다.

**100건 모두 문서 크기가 해당 viewport와 같고, 44px 미만으로 수집된 조작 영역과 외부 요청은 각각 0건이다.** 이는 준비된 학습 상태를 실제 앱에 렌더해 측정한 레이아웃 근거이며, 100번의 학습 완주를 뜻하지 않는다.

|---|---:|---:|---:|---:|---:|---:|

위 후보 수는 수정 중 수집한 원본값을 그대로 보존한 것이다. 아래 최종 재검증과 후보의 실제 표시 상태를 함께 해석한다. 후보를 일괄 오류로 계산하지 않는다.

## 최종 재검증

작성 시점의 `rechecks.json`은 지도 5건, 낮은 가로 정원 2건, 768×1024 세로 화면 5건으로 총 12건이다. 12건 모두 문서 크기는 viewport와 같고 44px 미만 조작 영역은 0건이다. 원본은 후속 검증이 추가될 수 있다.

- **지도 글자:** 장소 이름 실제 20px, 상태·다음 탐구 실제 16px로 역배율 보정했다. 재검증에 남은 작은 글씨 후보 15개는 직접 글자가 없는 `world-node` 부모 버튼이다. 자식에 적용한 실제 글자 크기를 기준으로 판정한다.
- **낮은 정원:** 873×580에서 프레임이 약 59px로 줄고 세로 조작 버튼이 잘리던 문제를 수정했다. 기존 `grid-row:3 / 6` 충돌을 없애고 최소 150px 프레임과 하단 가로 조작 행을 확보했다. 4개 조작 버튼이 프레임 안에서 각각 48px로 표시되는 것을 직접 확인했다. 그림 모드는 터치 칸을 유지하려고 최소 250px 행과 내부 스크롤을 허용한다.
- **세로 화면:** 768×1024의 메인·활동 6·활동 10·연구노트·엔딩 5건은 문서 가로 넘침이 없다. 활동 10의 긴 내용은 활동면 내부에서 스크롤한다. 실제 교실 운영 기준은 태블릿 가로 화면이다.
- **연구노트:** 표지 발췌를 짧은 발견 문장으로 교체하고, 좁은 표지의 중복 부제 및 낮은 화면의 발췌를 숨겼다. 전체 일기와 확인 상호작용은 팝업에 유지한다. 실제 1280×720 표지의 높이 386px와 scrollHeight 386px가 같고, 마지막 라벨 끝 603px가 하단 안내 시작 630px보다 위에 있다.

`cover-checks.json`의 5개 가로 프로필 × 5개 표지 **25건 모두 clientHeight와 scrollHeight가 같아 카드 내부 잘림이 없다.**

|---|---:|---:|
| 873×580 | 5 | 268 / 268px |
| 906×755 | 5 | 435 / 435px |
| 1024×768 | 5 | 444 / 444px |

## 자동 후보를 해석한 근거

- `outside`: 닫힌 details 안의 돌리기·시험 기록, 연결 완료 후 숨긴 연잎 선택지, 활동 내부 스크롤 아래의 도움말, 이동 가능한 지도 장소가 포함된다. 지도는 끌어서 이동하거나 전체 보기로 접근한다. 화면 밖 좌표 하나만으로 버튼 잘림을 확정하지 않는다.
- `smallText`: 최초 수집의 수첩 14px, 지도 상단 문구 12px, 낮은 엔딩 안내 14px는 16px 하한으로 수정했다. 지도 원본의 computed 13.6px 이름은 당시 부모 배율을 곱하면 실제 17px였다. 최종값은 이름 20px·상태 16px다.
- `images`: 최초 수집의 40개 이미지 후보는 5개 파일의 반복 기록이며, 모두 로컬 파일이 존재한다. 연결 후 숨긴 연잎 이미지와 접힌 시험 기록의 가방 이미지가 포함된다. 재검증 지도 이미지 후보 6개도 모두 로컬 파일이 존재한다. 이 배열만으로 다운로드 실패나 깨진 이미지를 주장하지 않는다.
- `panels`: 최초 측정의 25개 화면은 하나 이상의 활동 패널에서 세로 스크롤이 있었다. 최종 낮은 정원과 세로 화면도 필요한 내부 스크롤을 허용한다. 글자 축소나 문서 전체 넘침으로 숨기지 않는다.

## 직접 확인과 제한

검증 담당자가 연구노트 팝업에서 오답 단서 → 정답 피드백 → 읽었어 스티커 동작을 직접 확인했다. 최종 캡처는 `notebook.png`, `notebook-popup.png`에 보존했다. 앞선 현장 화면은 `field.png`를 참고한다.

이번 자료는 렌더링·배치·일부 상호작용의 근거다. 전 활동의 처음부터 끝까지 학습 완주, 실제 기기 터치·펜 조작, 교실 동시 접속과는 별개다. 해당 검증 없이 레이아웃 결과만으로 전체 콘텐츠 11점을 확정하지 않는다.
