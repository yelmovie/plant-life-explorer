## 확인한 증거

- **E1 자동 검사:** `npm run check`, `npm test`, `npm run build`. 문법 검사 24파일·테스트 53개 통과. 배포 파일은 `dist/` 104파일·14,994,823B다. 로컬 미리보기는 127.0.0.1:4332에서 dist를 제공한다.
- **E2 화면:** `design-20261020/layout.json`에 55개 활동 프로필과 20개 주요 화면 기록을 남겼다. 873×580·906×755·1280×800·1920×1080에서 10개 활동과 메인·지도·보고·최종·엔딩을 확인했다. 1024×768·1440×900은 주요 5활동, 375×812·768×1024는 2활동을 추가 확인했다. QA 준비 기록은 학생 성취 증거가 아니다.
- **E3 최대 상태:** 분류 확인 후 근거 선택지, 겨울 예상 선택, 발명 전·후 예상, 비 시험 비교가 펼쳐진 상태를 확인했다. 기본 접힌 상태만 보고 판단하지 않았다.
- **E4 실제 조작:** 시작→지도 걷기→의뢰, 새 기록에서 잎 관찰·오답 재관찰·두 기준 분류→복구 보상, 새로고침 복원, 두 식물의 계절 사진·연결, 잎자루 쓸어 자르기·물속 누르기, 정원 5칸 쓸기·한 번 되돌리기, 가방 덮개 변경·동일 조건 시험·근거 선택, 보고→혼자 탐구 표시→선인장 적용→엔딩을 조작했다. 일부 경로의 이전 활동은 QA 준비 기록을 사용했다.

## 교육 동기·미션 가치

처음 시작할 때 보이는 사건은 “식물 기록이 뒤섞여 연구기지가 멈췄다”이다. 한 문장 답변은 “식물의 증거를 모아 리피와 잠든 정원을 깨우는 게임”으로 설명할 수 있다. 이는 학생에게 실제로 질문한 결과가 아니라 화면 문구를 플레이하며 판단한 결과다.

| 미션 | 해결할 문제 | 선택이 바꾸는 것 | 얻는 것 | 생활·전이 연결 |
|---|---|---|---|---|
| 관찰과 분류 | 뒤섞인 표본 기록 | 관찰 특징·분류 기준에 따라 잎의 자리가 달라지고 불일치 수를 고친다 | 특징과 두 기준 기록, 온실 복구, 빛씨앗 | 학교 화단의 잎도 기준에 따라 나누기 |
| 계절과 생활 | 끊긴 겨울 뒤 기록 | 예상 후 땅속을 확인하고 직접 남긴 겨울·다음 봄 사진을 잇는다 | 두 식물의 계절 증거, 꽃돔과 꽃길 선택 | 겨울에 시든 풀도 살아 있는 부분 살펴보기 |
| 환경과 특징 | 비어 있는 환경 기록 | 잎자루를 자르고 눌러 결과를 해석하고 환경·특징·도움을 연결한다 | 실험·환경 연결 기록, 물길 복구 | 연못 식물의 특징을 관찰 근거로 설명하기 |
| 정원 만들기 | 정해지지 않은 식물 자리 | 칠한 환경과 심은 위치가 정원의 모습·유효성에 반영된다 | 자신이 만든 정원과 배치 이유, 정원 복구 | 실제 화단의 식물 자리 생각하기 |
| 발명과 개선 | 비에 젖는 탐험 가방 | 겉면과 입구를 하나씩 바꾸면 겉면·수첩 결과가 달라진다 | 설계·전후 시험·설명, 공방과 가방 전시 | 내 가방의 겉면과 덮개 역할 구분하기 |

보상은 클릭 수·속도와 연결되지 않는다. 필요한 관찰·사진·설명·배치·한 부품 비교 조건을 채워야 한다. 예측이 틀린 것 자체를 벌점으로 삼지 않는다. 재도전 도장 두 종류는 첫 완료의 서로 다른 탐구 과정을 칭찬하며 등급이 아니다.

약한 활동은 2-2다. 첫 연결의 학습 판단은 있으나 완료 후 다시 같은 사진을 잇는 이유가 적다. 시간 제한·목숨 차감·오답 초기화는 추가하지 않았다. 학생이 자발적으로 다시 여는지는 수업 관찰이 필요하다.

## 디자인과 아이스크림 설정 점검

상·하단 띠를 없애고 전체 화면 그림 위에 네 개 공통 아이콘을 둔다. 시작 화면은 소리·설정만 오른쪽에 보인다. 연구 노트·지도·도움말은 설정 안에서 연다. 활동 조작면과 핵심 안내는 역할에 따라 투명도를 다르게 쓴다.

설정 순서는 음악·효과음·음량 → 시작 이야기·잠긴 엔딩 → 앱 정보 → 학생 → 교사 → 출처 → 초기화·닫기다. 실제 BGM이 없어 음악과 음량은 잠겨 있고 이유가 표시된다. 교사용 도구는 확인 코드 없는 전체 열기 한 개이며 엔딩 완료 기록을 만들지 않는다. 출처는 링크 없이 표시한다. 기존 프로젝트의 저작권자 표기를 유지했다.

가로 화면의 주요 다음 버튼·이미지 누락·44px 미만 버튼은 최종 검사에서 발견하지 못했다. 375px 세로에서는 문서 스크롤이 생기며 가로 태블릿과 같은 한 화면 배치를 보장하지 않는다. 설정 본문, 펼친 추가 기록과 엔딩 증명서의 내부 스크롤은 의도된 동작이다. 873×580 분류 근거 최대 상태에는 내부 여분 3px가 남지만 선택지와 다음 버튼은 모두 보인다.

## 개선 우선순위와 11점까지의 차이

1. **19 네트워크 8→11:** 미방문 활동까지 필요한 자산의 준비 상태를 관리하고 학교망·실제 오프라인 완주를 측정한다. 캐시 용량·갱신 실패 위험을 확인해야 한다. 현재 요청에서 오프라인 기능을 새로 확대하지 않았다.
2. **23 재플레이 9→11:** 관찰·계절에도 새로운 근거를 찾거나 기존 판단을 고칠 목표를 설계하고 학생의 자발적 재방문을 관찰한다. 반복 클릭 배지는 추가하지 않는다.
3. **8 유지보수 9→11:** 기존 CSS 보정층을 화면별 기준으로 정리하고 새 활동 추가 절차를 문서화한다. 전체 재설계 없이 회귀 범위를 나누어 진행해야 한다.

다른 감점은 학생 효과 측정(1), 교육과정 공식 원문 전체 대조(2), 새 기록 연속 완주(5), 화면 함수 분리(6), 강제 WebGL 실패 실험(7), 기존 개별 스타일 통합(9), 실물 기기(13), 학교 로딩(17), 생성 서비스 이용 조건 확인(21)을 각각 재검증해야 해소할 수 있다. 확인하지 않은 항목을 문서 보완만으로 11점으로 올리지 않았다.
