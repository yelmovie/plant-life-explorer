# 스테이지 선택 개선 · 2026-10-19

아이스크림 스킬의 탐험 지도 구성을 적용했다. 기존 배경·건물·리피 에셋과 다섯 미션의 완료 조건을 유지한다.

- 다음 탐구·완료·잠금을 번호, 문구, 색으로 표시하고 다음 목적지 버튼을 제공한다.
- 장소 선택, 길 클릭, 방향판, 방향키/WASD로 리피가 기존 길을 따라 이동한다. 강이나 숲을 가로질러 이동하지 않는다.
- 전체 지도와 리피 추적 보기는 같은 좌표 변환을 사용한다. 잠긴 곳은 실제 선행 탐구와 이동 버튼을 안내한다.
- 교사용 전체 해금은 비밀번호 없이 실행하고, 미리보기 중 저장을 차단한다. 종료·새로고침 후 학생 기록으로 돌아간다.
- 지도 로딩 실패 시 기록을 보존한 채 다시 불러올 수 있다.

검증: 구문 검사, Node 테스트 48개, 빌드 통과. 분리된 Chromium 프로필에서 잠금 안내·정상 입장·완료 버튼·다음 단계 해금·저장 복원·미리보기 격리·입력 해제를 확인했다. 관찰·분류 증거를 테스트 저장본에 준비한 뒤 실제 완료 버튼으로 진행했다. 결과는 `results.json`, 화면은 `map-1280.png`·`map-768.png`에 있다.

1024×768, 1180×820, 1280×800, 768×1024, 820×1180에서 가로 넘침·주요 대상 가림·44px 미만 조작부가 없었다. 검증 입력은 마우스·키보드·브라우저 터치 에뮬레이션과 합성 pointercancel이며, 실제 태블릿 터치는 미검증이다.

구현·로컬 빌드까지 완료했으며 공개 배포는 하지 않았다. 기존 `src/spatial.js` 작업 내용은 보존했다.

브라우저 회귀 검사는 로컬 서버를 실행한 뒤 `node tests/stage-map.browser.mjs`로 실행한다. 필요하면 기존 설치 경로를 `PLAYWRIGHT_MODULE_PATH`, `BROWSER_EXECUTABLE`, 서버 주소를 `STAGE_MAP_URL`로 지정한다.
