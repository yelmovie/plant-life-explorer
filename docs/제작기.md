# 초록정원 연구기지 제작기

식물을 관찰한 기록이 다음 판단과 결과물에 쓰이는 탐구 게임이다. 리피와 함께 뒤섞인 식물 기록을 복구하며 다섯 연구 장소를 깨운다.

잎 관찰·두 기준 분류, 겨울과 다음 봄의 기록 연결, 잎자루 실험과 환경 연결, 정원 설계, 연잎을 본뜬 가방의 한 부품 비교가 이어진다. 마지막에는 새 식물인 선인장의 특징을 환경과 연결하고 자신이 만든 정원·가방·탐구 기록을 함께 본다. 학습효과 자체는 학생 수업에서 별도 확인해야 한다.

브라우저의 HTML·CSS·JavaScript와 로컬 Three.js를 사용한다. 잎자루와 알로에는 GLB 모형을, 정원과 가방 일부는 코드로 만든 모형을 쓴다. 모형은 구조와 기능을 설명하기 위한 표현이며 실제 생육·유체 시뮬레이션이 아니다. 입체 표현을 쓰기 어려울 때는 그림과 버튼으로 활동할 수 있다.

배경·캐릭터·관찰 그림과 도장은 생성형 AI로 만든 자산과 기획자가 제공한 원안을 활용했다. 출처와 동봉 라이선스, 생성 서비스에 관한 확인 사항은 `assets/CREDITS.md`에 기록한다. 학생 이름·학번은 받지 않으며 활동 기록은 현재 브라우저에 저장한다.

개발·검증은 `README.md`, 디자인 기준은 `DESIGN-SYSTEM.md`, 실제 실행 결과와 한계는 최신 `docs/reviews/FINAL-CHECK-*.md`에서 확인한다.
