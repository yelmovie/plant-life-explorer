# 초록정원 연구기지 제작기

식물을 관찰한 기록이 다음 판단과 결과물에 쓰이는 탐구 게임이다. 리피와 함께 뒤섞인 식물 기록을 복구하며 다섯 연구 장소를 깨운다.

잎 관찰·두 기준 분류, 겨울과 다음 봄의 기록 연결, 잎자루 실험과 환경 연결, 환경에 맞는 정원 식물 심기, 연잎을 본뜬 가방의 한 부품 비교가 이어진다. 마지막에는 새 식물인 선인장의 특징을 환경과 연결하고, 다섯 탐구를 연구노트와 짧은 탐험 일기로 돌아본다. 학습효과 자체는 학생 수업에서 별도 확인해야 한다.

브라우저의 HTML·CSS·JavaScript와 로컬 Three.js를 사용한다. 정원은 식물 그림과 알로에 GLB를 함께 쓴다. Meshy 잎자루 단면은 납작한 구조가 확인되어 현재 실험에는 코드로 만든 단순화 모형과 투명 관찰 그림을 사용한다. 가방은 제공된 그림이 기본이며 단순화한 코드 모형도 볼 수 있다. 실제 생육·유체 시뮬레이션이 아니며, 입체 표현을 쓰기 어려울 때는 그림과 버튼으로 활동할 수 있다.

배경·캐릭터·관찰 그림과 도장은 생성형 AI로 만든 자산과 기획자가 제공한 원안을 활용했다. 메인·엔딩 음악은 기획자가 Suno로 만든 AI 생성 음원이며 영상 중에는 정지한다. 출처와 동봉 라이선스, 생성 서비스에 관한 확인 사항은 `assets/CREDITS.md`에 기록한다. 학생 이름·학번은 받지 않으며 활동 기록은 현재 브라우저에 저장한다.

개발·검증은 `README.md`, 디자인 기준은 `DESIGN-SYSTEM.md`, 실제 실행 결과와 한계는 최신 `docs/reviews/FINAL-CHECK-*.md`에서 확인한다.
