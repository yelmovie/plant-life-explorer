# 식물의 생활 개념 설명 정교화 · 2026-11-09

## 범위
기존 활동별 개념 영화가 없어, 완료한 탐구의 기록 속 교사 정리 아래에 선택형 3장면 그림 설명 5개를 추가했다. 영화라고 표시하지 않는다. 잎의 분류 기준, 겨울눈과 같은 식물, 부레옥잠 잎자루 공기, 서식 환경, 연잎과 덮개의 다른 역할을 구별한다. 인트로·아웃트로 자막 핵심어 강조와 감소 모션도 보완했다.

- 지도·오디오·학생 기록/해금 조건을 바꾸지 않는 개념 전용 수정이다.
- 기존 과학 도해와 영상의 핵심 장면을 확인해 재사용했다. 이 변경에서 신규 생성 이미지나 원본 영상·오디오 바이너리 변경은 없다.
- 자막은 DOM 텍스트와 의미 있는 강조 표시를 유지한다. 강조색뿐 아니라 굵기, 밑줄, 현재 장면 상태도 사용한다.
- 그림 설명은 자동으로 시작하지 않는다. 사용자가 이어 보기를 선택하면 6초마다 다음 그림을 보여 주고 마지막에서 멈춘다. 장면 선택·패널 닫기·화면 숨김 때 멈추며 학생 기록이나 시청 강제 조건을 추가하지 않는다.
- 자막 전환은 짧게 한 번만 실행한다. 감소 모션에서는 반복 장식과 전환을 제거한다. 화면을 떠나거나 설명을 닫으면 재생을 정리한다.

## 검증
- 157개 테스트.
- 실행 명령: `npm test; npm run check; npm run build`. 최종 프로덕션 빌드 통과.
- 실제 소스 컴포넌트와 기존 미디어를 Chrome에서 873×580, 1024×768, 1920×1080으로 검사했다. 감소 모션, 장면 선택, 버튼 가림, 자막 강조, JavaScript 오류를 확인했다.
- 실제 노트 구조의 873×580·1024×768에서 5개 × 3장면 = 30개 레이아웃을 추가 확인했다. 모든 자막이 18px 이상이며 이미지가 정상 로드되고 가로 잘림 없이 스크롤로 컨트롤에 접근할 수 있다. 일부 완료 상태는 테스트 DOM으로 동일 위치에 삽입했다.
- 대표 그림 설명의 이어 보기, 다음 그림 진행, 종료 시 정리를 확인했다. 인트로·아웃트로 감소 모션 정지 시작과 초기 컨트롤을 확인했다. 그림 설명은 새 영화가 아니며 스토리 전체 재생이나 후반 자막을 동적으로 재검증한 결과는 아니다.
- 전체 게임 진행·학생 계정·실물 태블릿·운영 배포 검증을 대신하는 결과는 아니다. 배포 스냅샷은 통합된 정확한 커밋으로 별도 빌드해야 한다.

## 배포 주의
기존 동시 작업을 보존해 최신 origin에 통합하고 일반 push만 한다. ignored 원본 미디어는 동일 프로젝트에서 해시를 확인해 보충한다. 다른 프로젝트 자산이나 임의의 dirty 소스를 섞지 않는다.
