# 2단계 계절 타임랩 3D — 설계와 Meshy 입력 자료 (2026-10-25)

최종점검(`../reviews/FINAL-CHECK-20261025.md`)에서 2단계 '계절과 생활'이 가장 약한 스테이지였다. 완주한 뒤에 같은 사진을 다시 이을 이유가 없다는 점이 약점이다. 2D 계절 그림을 입체 타임랩으로 바꾸고, 겨울에도 살아 있는 부분을 학생이 직접 찾게 하는 설계다. 이 문서는 설계와 GLB 제작 자료까지만 담는다. GLB는 사용자가 Meshy에서 만들고, 연결 구현은 GLB를 받은 뒤에 한다.

- 복붙용 Meshy 프롬프트: [meshy-prompts.txt](meshy-prompts.txt)
- 기본 이미지 생성 프롬프트(재생성용): [image-prompts.txt](image-prompts.txt)
- 입력 그림 미리보기: [inputs-preview.jpg](inputs-preview.jpg)

## 1. 왜 이렇게 나누었나

기존 벚나무 그림(`cherry_tree`, `meshy_m4_cherry`)은 잎이 가지를 덮고 있다. 이 그림을 Meshy에 넣으면 잎 덩어리 하나가 만들어지고, 계절마다 같은 나무를 보여 줄 수 없다. 계절마다 모델을 따로 만들면 줄기 모양이 달라진다. 그러면 "같은 나무가 겨울을 지나 다시 자란다"는 2단계의 핵심이 흐려진다.

그래서 **계절이 바뀌어도 그대로인 부분(줄기·가지·뿌리)만 Meshy로 만들고, 바뀌는 부분(잎·단풍·꽃·겨울눈)은 코드로 얹는다.** 같은 몸통이 한 번도 바뀌지 않으므로 학생은 같은 식물을 따라가게 된다.

| 구분 | 만드는 곳 | 계절마다 하는 일 |
|---|---|---|
| 벚나무 줄기·가지·뿌리 (M1) | Meshy | 그대로 |
| 벚나무 잎·단풍·꽃·겨울눈 | 코드(작은 그림 여러 장을 가지 끝에 배치) | 여름 잎 → 가을 단풍과 낙엽 → 겨울 맨가지와 겨울눈 → 봄 꽃과 새잎 |
| 씀바귀 뿌리 (M2) | Meshy | 그대로 |
| 씀바귀 잎 방석 (M3) | Meshy | 여름 초록 → 가을 누렇게 → 겨울 갈색으로 납작 → 봄 작은 새잎 (색·크기만 코드로 바꿈) |
| 씀바귀 꽃줄기 (M4) | Meshy | 여름에만 보이고, 가을에 시들고, 겨울·봄엔 없음 |
| 흙 단면 상자·눈·풀 | 코드 | 겨울 눈 덮임, 봄 새 풀. 앞면 흙판을 열면 땅속이 보임 |

## 3. Meshy 비용과 순서

| 항목 | 값 |
|---|---|
| 가격 기준 | Meshy API 가격표(2026-10-25 확인): Image to 3D, meshy-6/7.1, 질감 2K 포함 **모델당 30크레딧**. 질감 없이 20, 형상 고해상도 옵션 +5 |
| 이번 4개 | **120크레딧**. 재생성 1회씩을 여유로 잡으면 최대 240 |
| 현재 잔액 | **1,574크레딧** (월 1,360은 2026-11-10 초기화, 영구 214) |
| 권장 순서 | **M1 먼저 1개** 만들어 가지·뿌리 두께를 확인한다 → 괜찮으면 M2~M4 진행 |

웹 화면의 크레딧 표시가 위와 다르면 웹 표시가 우선이다. 이번 기본 이미지에는 힉스필드 14크레딧을 썼다(고품질 4장 × 2.75 + 질감 3장 × 1). 남은 힉스필드 잔액은 32.25다.

## 4. 화면과 조작 설계 (2단계 '계절을 바꿔 봐요')

```
┌ 계절을 바꿔 봐요 ───────────────────────────────┐
│ 오늘의 연구 │   [ 흙 상자 위 벚나무 · 돌려 보기 ]     │
│  ① 계절 따라가기 │        ↻ 드래그로 회전 · 두 손가락 확대 │
│  ② 땅속 확인  │   [여름][가을][겨울][다음 봄]  ▶ 1년 재생 │
│  ③ 사진 남기기 │   [땅속 열기]  [이 모습 찍기]           │
│ 리피 말풍선   │                                      │
└──────────────────────────────────────────────────┘
```

1. **시간 다이얼**: 기존 4계절 버튼과 손잡이는 그대로 둔다. 계절을 바꾸면 0.8초 동안 잎이 물들고 떨어지거나 꽃이 피는 연출이 나온다. **▶ 1년 재생**은 여름부터 다음 봄까지 6초 동안 자동으로 넘긴다(동작 줄이기 설정에서는 바로 바뀜).
2. **돌려 보기**: 기존 입체 화면처럼 드래그로 회전하고 두 손가락으로 확대한다. 되돌리기·'그림으로 보기' 버튼을 유지한다.
3. **땅속 열기**: 흙 상자 앞면이 열리며 뿌리가 보인다. **겨울에는 기존 규칙대로 "땅속에 무엇이 남아 있을까?" 예상을 먼저 고른 뒤에만 열린다.**
4. **이 모습 찍기**: 기존 `seasonalRecords`·`seasonPhotos` 기록을 그대로 쓴다. 3D로 바뀌어도 저장 형식은 바뀌지 않는다.
5. **실패 대체**: WebGL을 쓸 수 없거나 GLB를 받지 못하면 지금의 2D 계절 그림으로 같은 탐구를 한다.

## 5. 확정한 결정과 현재 구현 (2026-10-25)

사용자 결정: **겨울눈 찾기와 초봄 단계를 둘 다 넣는다.** 범위는 2단계 본 탐구(활동 3)로 하고, 현장 임무 2의 사진 순서 맞추기는 2D로 둔다.

GLB가 없어도 되는 부분은 먼저 구현했다. 3D가 안 되는 기기에서 보는 2D 화면도 같은 기록·판정을 쓴다. GLB가 오면 3D 장면을 같은 상태 위에 얹으면 된다.

| 결정 | 지금 동작 (2D) | 3D가 오면 |
|---|---|---|
| A. 겨울눈 찾기 | 겨울에서 땅속 예상과 확인을 마치면 '관찰 렌즈로 겨울눈 찾기'가 열린다. 그림을 누르면 그 자리가 렌즈로 확대된다. 벚나무는 가지 끝 3곳, 씀바귀는 뿌리 머리 1곳을 찾으면 렌즈에 겨울눈·새눈 확대 그림이 뜨고 표시가 남는다. 굵은 줄기·하늘·땅속을 누르면 어디를 봐야 하는지 단서를 준다. '렌즈 도움'은 다음 자리를 보여 주고 힌트 횟수에 남는다. 완주 조건에는 넣지 않았다(더 해 보기). 연구노트 표지에 `겨울눈 n/4`가 남아 다시 열 이유가 된다 | M1 가지 끝 혹·M2 새눈 위치를 눌러 찾는다(광선 판정). 같은 `budsFound` 기록과 목표 수(`BUD_GOAL`)를 쓴다 |
| B. 초봄 단계 | 시간 손잡이가 여름→가을→겨울→**초봄**→다음 봄 5칸이 된다. 초봄은 기존 `cherry_bud_spring`·`sowthistle_bud_spring` 그림을 보여 주는 보기 전용 단계다. 사진 버튼이 없고, 겨울 예상 전에는 땅속을 열 수 없다. 사진 기록 키(0~3)는 그대로다 | 같은 나무에서 겨울눈이 부풀고 새잎 끝이 보이는 상태로 바뀐다 |

구현 파일은 다음과 같다. `src/winter-buds.js`(판정·도움 위치·저장 정리), `src/learning.js`의 `seasons()`·`bud-*` 동작, `src/art.js`의 `seasonArt`(초봄 그림·땅 높이), `src/model.js`(`budsFound`, 계절 0~4), `src/research-notebook.js`, `src/frame.css` §8. 테스트는 `tests/winter-buds.test.mjs` 4개다. 렌즈 확대 그림 `season_cherry_winter_bud`·`season_sowthistle_crown_bud`(씀바귀는 M2 입력 그림의 뿌리 머리를 잘라 씀)를 앱에 연결했다.

알려진 한계: 2D 계절 그림은 화면 비율에 맞춰 늘어난다. 906×755처럼 세로로 긴 칸에서는 나무가 길쭉해 보인다. 3D 장면으로 바뀌면 해결된다.

## 6. 성능·교실 기준

- 2단계에 들어갈 때만 GLB를 받는다. 지도에서 다음 장소로 2단계를 고르면 미리 받기 목록에 넣는다.
- GLB는 모델당 1MB 안팎이고 4개를 합쳐 3MB 이하로 한다. 30,000 삼각형 이하, 질감 1024px. 교사용 '수업 전 오프라인 준비' 목록에도 넣는다.
- 잎과 꽃은 한 번에 그리는 묶음(인스턴스)으로 처리한다. 저사양 태블릿에서도 30fps를 목표로 한다. 렌더링이 느리면 잎 개수를 자동으로 줄인다.

## 7. GLB를 받은 뒤 할 일

1. 블렌더로 원점·크기·방향을 맞춘다(기준은 `meshy-prompts.txt` 끝). 30,000 삼각형 이하로 줄이고 질감을 1024로 맞춘다. 원본은 `_source/original-glb/`에 보관한다.
2. 측면 두께를 확인한다. 90도 돌려도 가지·뿌리가 납작하지 않아야 한다. 잎자루 단면처럼 납작하면 재생성한다.
3. `spatial.js`에 `season` 장면을 추가한다. 2D의 `budsFound`·초봄 상태를 그대로 쓰고, 겨울눈 찾기는 렌즈 탭 대신 3D 광선 판정으로 바꾼다. 기존 2D와 같은 기록이 남는지 `tests/winter-buds.test.mjs`를 넓혀 확인한다.
4. 1280×800·906×755·1920×1080·873×580 화면과 그림 모드에서 새 기록 완주 시나리오를 다시 돌린다.
