## 3. Meshy 공통 설정

| 항목 | 값 |
|---|---|
| 메뉴 | Image to 3D |
| 모델 | Meshy-6 또는 최신 |
| 질감(Texture) | 켬, 2K |
| 메시(Topology) | Triangle |
| 조명 제거(De-light) | 켬 (있으면) |
| 받을 형식 | GLB |
| 비용 | 질감 포함 모델당 약 30크레딧 → 4개 약 120 (잔액 1,574) |

모델별 다른 값은 아래 각 칸에 적었어. 프롬프트 입력 칸이 있으면 영어 프롬프트를 그대로 붙여 넣고, 없으면 그림과 설정만 쓰면 돼.

## 4. 다 만들고 나서

1. 받은 GLB 4개를 `_source\original-glb\season-20261025\`에 넣는다.
2. "GLB 넣었어"라고 알려 준다.

그다음은 내가 한다.

- 크기·방향·원점 맞추기: 땅 높이를 0으로 두고, 벚나무는 땅 위 2.0, 씀바귀는 1.0으로 맞춘다.
- 용량 줄이기: 3만 삼각형, 질감 1024, 모델당 1MB 안팎.
- 정리한 GLB를 `assets/models/`에 넣고 2단계 3D 계절 장면에 연결한다. 2D로 먼저 넣은 초봄과 겨울눈 찾기가 그대로 3D로 이어진다.
- 90도 돌려서 납작한 모델이 있는지 확인한다. 납작하면 그 모델만 다시 만들어 달라고 할게.
