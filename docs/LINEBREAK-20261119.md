- **그대로 둔 것**: 「가라앉을 / 것 같아」, 「건조 / 구역」, 연구 노트 표지 제목, 기록 보관 창 버튼(「현재 활동 / 파일 보관」 등)처럼 뜻 단위로 고르게 나뉜 두 줄 이름표 — 한 줄로 만들려면 칸·글자 크기를 바꿔야 한다. 악당 대사(음성과 이어진 글)는 이미 `text-wrap: balance`가 있고 문제 0이라 손대지 않았다. 3D·캔버스에는 글자가 없다.
- **미확인**: 실물 iPad Safari·Android Chrome·전자칠판에서의 줄바꿈(Safari가 `text-wrap: balance`·`pretty`를 지원하지 않으면 예전 줄바꿈으로 보일 뿐 깨지지는 않는다).
