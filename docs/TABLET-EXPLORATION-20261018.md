## 계획과 실행 결과

1. **탐험 지도 확대 — 완료.** 다섯 연구 건물을 큰 지도에 배치. 장소 선택 시 두 활동을 보여 주는 입장 팝업. 기존 순차 해금과 빛씨앗 유지. 꽃길과 내 정원은 요청할 때 팝업으로 표시.
2. **활동 화면 통일 — 완료.** 왼쪽 캐릭터·현재 할 일, 중앙 큰 활동 장면, 하단 다음 버튼. 제목 아래의 중복 설명과 고정 기록 패널을 제거하고 기록·도움말 버튼으로 이동. 발명 활동의 필수 부품 선택과 근거 연결 패널은 계속 표시.
3. **이미지 적용 — 완료.** 온실 작업대 배경 1장 신규 생성. 기존 표본·캐릭터·지도·보상 건물 재사용. PNG 원본은 assets/generated, 웹용 WebP는 약 259 KB. 생성 도구 기본 경로의 원본은 도구 규칙에 따라 남겼으며 프로젝트 사용본은 D:에 보관.
4. **보고와 완성 화면 정리 — 완료.** 발견 선택 / 가방 소개를 두 화면으로 구분. 결과 지도·내 정원·가방을 완성 화면에 함께 배치.
5. **검증·빌드 — 완료.** 아래 검증 수행. 세로 화면과 큰 글자는 자연스럽게 스크롤하는 접근성 예외를 유지.

## 검증

- 1280×800: 10개 활동 및 홈·지도·보고·최종 확인·완성 = 15개 상태.
