# 초록정원 화면 규칙

현재 스타일은 기존 온실·숲길 그림과 로컬 Jua/Pretendard 글꼴을 유지한다. 기본 화면 틀은 `src/layout.css`, 요청한 장면과 최종 반응형 보정은 그 다음에 읽는 `src/scene-refinements.css`에서 조정한다. 영상은 마지막 `src/story.css`가 담당한다. 앞선 스타일시트는 기존 활동과 인쇄 화면의 기본값을 제공한다.

## 공통 틀

- 그림은 `100dvh` 전체에 표시한다. 상·하단 띠를 만들지 않는다.
- 왼쪽 위는 홈·이전, 오른쪽 위는 소리·설정이다. 홈 화면에서는 왼쪽 두 버튼을 숨긴다.
- 연구 노트·지도·활동 기록·도움말·전체화면·큰 글자는 설정의 앱 정보 안에서 연다.
- 활동 제목은 작은 종이색 칩, 조작면은 반투명, 안내와 선택지는 밝은 바탕을 쓴다.
- 뒤로/지도와 다음 동작은 아래 양쪽에 놓는다. 조작면을 덮지 않는다.

## 조정할 토큰

| 토큰 | 용도 | 기본값 |
|---|---|---|
| `--hud-edge` | 아이콘 가장자리 여백 | 16px |
| `--hud-size` | 공통 아이콘 버튼 | 48px, 전자칠판 60px |
| `--hud-top` | 그림이 보이는 상단 안전 영역 | 80px |
| `--frame-gap` | 활동면 사이 간격 | 16px |
| `--frame-footer` | 하단 동작 공간 | 72px |
| `--frame-guide` | 캐릭터와 안내 폭 | 120~176px |
| `--frame-text` | 활동 본문 크기 | 20~24px |
| `--font-size-sm`, `--font-size-md` | 본문·버튼 크기 | 최소 20px |
| `--font-size-xs` | 보조·상태·설명 표지 | 최소 16px |
| `--frame-title` | 활동 제목 | 25~36px |
| `--frame-paper` | 안내·제목의 밝은 바탕 | 크림색 94% |
| `--frame-tint` | 그림 위 활동면 | 크림색 24% |

버튼의 상태·색상·글꼴 토큰은 `src/polish.css`를 따른다. 상태를 색으로만 표현하지 않고 테두리·체크·문구를 함께 쓴다. 기존 파일의 색상과 크기가 모두 토큰화된 것은 아니므로 후속 변경 때 `layout.css`와 `scene-refinements.css`의 우선순위를 함께 확인한다. 새 버튼은 48px을 기준으로 만들며, 기존 44~47px 버튼을 이유 없이 일괄 확대하지 않는다.

지도는 부모의 `--map-scale`로 확대·축소된다. 장소 이름은 `calc(20px / var(--map-scale))`, 상태와 다음 탐구 표지는 `calc(16px / var(--map-scale))`를 사용해 실제 표시 크기를 유지한다. 직접 글자가 없는 `world-node` 부모 버튼의 computed font-size만 보고 글자 크기를 판정하지 않는다.

## 크기가 달라질 때

873×580, 906×755, 1024×768, 1280×800, 1920×1080에서 메인·10개 활동·5개 현장 탐구·연구노트·마지막 적용·엔딩·지도를 확인한다. 2026-10-24 검증은 이 조합 100건과 768×1024 세로 화면 5건을 포함한다. 761~1050px의 환경 연결은 보드를 전체 폭에 놓는다. 낮은 가로 화면의 가방 시험은 활동면과 설명면을 나누고 필요한 기록만 내부에서 스크롤한다. 실제 수업은 가로 화면을 기준으로 한다.

활동 화면은 제목·여정·하단 동작을 유지하고 내용이 긴 활동면 안에서 스크롤한다. 가로 문서 스크롤을 만들거나 글자를 줄여 맞추지 않는다. 현장 관찰의 두 버튼은 같은 폭의 2열이며, 낮은 화면에서는 관찰 그림 슬롯을 줄여 조작 접근을 빠르게 한다.

높이 650px 이하의 가로 정원은 모드·땅 도구를 각 48px 행에 놓고, 정원 프레임에 최소 150px을 확보한다. 회전·확대·초기화·그림 전환은 하단 가로 행으로 모으며 캔버스 아래 54px을 분리한다. 그림 모드는 24칸의 터치 영역을 유지하기 위해 프레임 행을 최소 250px로 두고 활동면 내부 스크롤을 허용한다. 이전 활동용 `grid-row:3 / 6`이 새 정원 작업대에 적용되지 않도록 프레임 행·열을 `auto`로 초기화한다.

연구노트 표지는 짧은 발견 한 문장과 기록 상태를 보여 준다. 전체 탐구 일기·적용 생각·확인 문제·읽었어 스티커는 표지를 누른 팝업에 담는다. 좁은 표지에서는 중복 부제를 숨기고, 높이가 낮으면 표지 발췌 문장도 숨겨 제목·기록·펼치기 동작을 유지한다. 팝업의 전체 내용은 생략하지 않는다.

설정은 본문만 스크롤하고 제목과 닫기·초기화 버튼은 유지한다. 관찰 그림과 입체 모형을 바꾸어도 학습 기록·판정은 동일하다.

실측 근거와 자동 수집값 해석은 `docs/reviews/final-20261024/LAYOUT-SUMMARY.md`를 따른다. 준비된 상태의 화면 검증과 학습자가 모든 단계를 직접 완주한 검증은 구분한다.
