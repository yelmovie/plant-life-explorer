# MVP 검증 기록

2026-09-23 / Node.js v24.11.0 / Codex 내장 Chromium 브라우저.

## 자동 검사
- JavaScript 구문 검사: `npm run check` 통과.
- 순수 로직 테스트: `npm test` 8개 통과.
- 빈 상태·단계 잠금, 관찰 없는 정답 분류 차단, 계절 기록 의존성, 지형 면적·배치 근거, 설계가 다른 시험 이력, 손상 저장 복원, 저장 왕복, 현재 산출물의 최종 검증을 검사했다.

## 브라우저에서 직접 수행한 흐름
- 메인 → 사건 소개 → 지도 → 표본 세 종류 확대와 특징 6개 기록.
- 일부러 벚나무를 잘못 분류한 상태에서 완료 불가 확인, 수정 후 증거 1 획득.
- 두 식물의 봄·여름·겨울을 땅속 보기로 기록, 벚나무 겨울/다음 봄 증거 연결 → 증거 2.
- 잎자루 절단 → 확대 → 물속 → 누르기 → 기록, 알로에 비교, 식물 세 종류 환경·특징 연결 → 증거 3.
- 세 환경을 각 3칸 칠하기, Undo로 마지막 칸 복구 확인, 재편집.
- 부레옥잠을 건조 구역에 놓았을 때 완료 불가 확인. 세 식물의 알맞은 배치와 근거 확인 → 증거 4.
- 정원 배치 화면 새로고침 후 지형·식물·근거와 완료 가능 상태 복원 확인.
- 기본 천/열린 입구 가방 시험에서 두 기능 미충족, 연잎 표면/덮개로 개선 후 재시험 → 증거 5.
- 증거 5종 보고 → 새 표본 분류·선인장 환경 판단·정원 시운전·발명 기능 연결 → 코어 가동 → 정원·발명품·인증서가 있는 엔딩 확인.
- 새로고침 후 엔딩 보존, 지도 복구율 100%, 실제 편집 지형의 지도 반영 확인.
- 연구 노트와 설정, 전자칠판 큰 글자 전환, Enter 키로 코어 가동 확인.
- 해당 흐름에서 브라우저 콘솔 error/warn 없음.

## 화면 검사
- 메인, 선택 지도, 표본, 증거판, 실험, 정원, 가방 시험을 실제 스크린샷으로 확인했다.
- 1024×768에서 활동 주 행동 버튼이 viewport 안에 있음(하단 754px) 확인.
- 메인과 표본 화면 기준 375/768/1024/1280/1440px에서 문서 가로 넘침 없음. 표본 화면은 모든 너비에서 주 행동 버튼 노출 확인. 메인의 이미지 로드 정상 확인.
- 1024×768 큰 글자 모드에서는 수첩 아래 부분에 세로 스크롤이 필요하며 주 행동은 하단에 유지한다.
- 모바일은 보조 지원이다. 실제 수업 목표는 가로 태블릿/전자칠판이다.

## 남은 실기기 검수 및 범위
- 실제 iPad/Android의 두 손가락 확대·펜·드래그, 전자칠판 실제 거리 가독성은 미검증.
- 프린터 출력은 미검증(인증서 인쇄 버튼과 print CSS 구현).
- 학습 식물은 단순화한 SVG 관찰 그림. 사진 표본·상용 수준 세밀한 애니메이션과 픽셀 타일셋은 후속 제작 범위.
- 가방 시험은 기능을 이해하는 규칙 기반 모형으로, 실제 제품 성능을 예측하지 않는다.
- 공식 교과서 판본별 문장·표본 타당성과 학습량은 교과 전문가의 최종 검수가 필요하다.
- 온라인 배포, 계정, 다중 사용자/기기 동기화, 영상·음성·다종 발명품은 이번 MVP 범위 밖이다.

## 실행 메모
기본 포트 4173이 다른 프로세스에서 사용 중이어서 이 프로젝트는 4318을 사용한다. 기존 프로세스는 변경하지 않았다. 브라우저 테스트 기록은 127.0.0.1 origin에 있고 사용자 미리보기는 localhost origin으로 분리한다.

## 공통 아이콘·관리자 전체 해금 추가 검증
- 자동 테스트 10개 통과. 관리자 해금 시 완료 기록이 바뀌지 않는지, 해금/음소거 저장 복원, 이전 페이지 순서 및 일반 모드 잠금 복원을 추가 검증했다.
- 브라우저에서 전체 15개 화면에 직접 진입하여 홈/이전/소리/설정 공통 버튼 4개가 모두 존재함을 확인했다.
- 관리자 토글 1회로 단일 목록의 모든 페이지 진입 가능. 10장에서 9장으로 이전 이동, 10장 새로고침 후 해금·음소거 유지 확인.
- 해금 해제 시 일반 지도 잠금 4개 복원, 메인 이전 버튼 비활성 확인.
- 375px에서 가로 넘침 없고 네 아이콘 버튼은 모두 48px. 홈/이전은 왼쪽, 소리/설정은 오른쪽에 배치됨.
- Web Audio 조작 효과음 추가. 음소거/해제 UI와 콘솔 오류 없음 확인. 실제 스피커 출력의 청음은 별도.
