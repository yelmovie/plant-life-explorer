## 0. 이번 심화 설계의 핵심

이 문서는 기존 「초록정원 연구기지」 설계를 폐기하지 않고, 이미 확정한 5 Stage·10화면 구조와 좋은 학습 활동을 유지하면서 다음을 강화한 버전이다.

- 5개의 Stage를 서로 따로 노는 활동이 아니라 **하나의 사건을 해결하는 5개 Mission**으로 연결
- 각 Mission 완료 시 별·코인이 아니라 **학습과 직접 연결된 Evidence** 획득
- Mission 결과가 메인 연구기지와 정원에 남는 **World Change** 구현
- 캐릭터를 장식물이 아니라 **퀘스트·실험·기록·설계 역할을 가진 NPC 시스템**으로 재정의
- 모든 Mission에 **ACTION → REACTION → THINK → ADJUST → RETRY**의 Micro Loop 적용
- 단순 정오판정 대신 **식물의 변화, 실험 결과, 배치 결과, 설계 성능** 자체가 피드백이 되도록 수정
- 종이 학습지로 대체하기 어려운 **핀치 줌, 회전, 타임라인 스크럽, 가상 절단, 누르기 실험, 지형 제작, 배치, 설계, 시뮬레이션**을 핵심 행동으로 배치
- 최신 샘플 화면 방향을 반영해 **로봇 캐릭터 제거**
- 프로젝트 전용 캐릭터를 **리피·방울·꽃이**로 통일
- 캐릭터는 해당 화면에서 실제 역할이 있을 때만 등장
- UI 버튼, 카드, 탭, 진행률, 툴팁, 모달 등은 **CSS/DOM으로 구현**하고 이미지 에셋 남용 금지

학생의 최종 경험은 다음이 되어야 한다.

> “식물 문제를 여러 개 풀었다.”  
> 가 아니라  
> **“내가 식물을 관찰하고, 기준을 만들고, 실험하고, 증거를 연결하고, 정원을 다시 만들고, 식물의 특징으로 생활 문제까지 해결했다.”**

# ① 기존 설계 진단

## 1. 현재 설계의 강점

현재 10개 화면은 다음 학습 흐름을 가진다.

```text
관찰
→ 분류
→ 계절에 따른 생활 방식 조사
→ 증거로 설명
→ 환경과 특징의 관련성 실험
→ 서식지 판단
→ 환경 설계
→ 식물 배치
→ 식물 특징 활용 설계
→ 테스트·개선
```

이는 다음 성취기준과 직접 연결된다.

- `[4과03-01]` 여러 가지 식물을 관찰하여 특징에 따라 식물을 분류할 수 있다.
- `[4과03-02]` 다양한 환경에 서식하는 식물을 조사하여 식물의 생김새와 생활 방식이 환경과 관련되어 있음을 설명할 수 있다.
- `[4과03-03]` 식물의 특징을 이용하여 일상생활에서 활용할 수 있는 생활용품을 설계하여 협력적으로 소통할 수 있다.

이미 설계된 다음 행동은 종이 활동지보다 디지털에 적합하다.

- 식물 표본 확대·회전
- 특징 핫스폿 탐색
- 분류 규칙 생성
- 타임라인 스크럽
- 가상 절단·확대
- 물속에서 눌러 공기 방울 관찰
- 식물 카드 서식지 배치
- 지형 직접 제작
- 가상 연구정원 구성
- 설계 부품 배치
- 제품 성능 테스트

Stage 4와 Stage 5에서 학생이 앞에서 얻은 정보를 이용해 정원을 구성하고 제품을 설계하므로, 단원 후반이 단순 객관식 종합문제로 끝나지 않는 점도 강점이다.

## 2. 기존 설계에서 게임성이 약한 부분

- 왜 이 연구를 해야 하는지 하나의 큰 사건이 부족함
- Stage 완료가 곧바로 다음 Stage 이동으로 이어져 **퀘스트 수행감이 약함**
- 각 Stage 결과가 다음 Mission의 자원으로 쓰인다는 느낌이 약함
- 실패가 대부분 “다시 선택” 수준이라 재도전의 의미가 약함
- 세계가 실제로 변하는 축적 구조가 부족함
- Final 화면이 발명품 성공으로 끝나면, 1~4 Mission에서 모은 학습 결과가 엔딩에서 다시 활용되지 않을 수 있음

따라서 이번 심화안에서는 **Evidence / World Change / Final Report / Final Mission**을 추가한다.

## 5. AI Slop 방지

단순 `설명 → 4지선다 → 정답 → 별 → 다음` 구조를 반복하지 않는다.

각 화면에서 학생 행동이 실제 현상을 바꾸게 한다.

- 잎을 확대해야 특징 데이터가 열림
- 규칙이 애매하면 분류가 겹쳐 보임
- 계절 슬라이더를 움직이면 식물 상태가 바뀜
- 부레옥잠 잎자루를 눌러야 실제 공기 방울이 발생
- 환경이 맞지 않으면 즉시 X가 아니라 **근거 체인이 끊어짐**
- 정원 지형이 부족하면 배치 가능한 식물이 줄어듦
- 제품 테스트가 실패하면 부족한 기능이 실제 결과로 드러남

# ② 단원 메인 퀘스트

## 사건 — 그린코어 안전정지

초록정원 연구기지의 중앙 생태 관리 장치 **그린코어**가 안전정지 상태에 들어간다.

연구기지 안의 식물 기록이 뒤섞이면서 다음 문제가 동시에 발생한다.

- 식물 표본의 특징 데이터가 일부 비어 있음
- 분류 기준이 정리되지 않음
- 계절별 생활 기록이 연결되지 않음
- 어떤 식물이 어떤 환경에 알맞은지 판정 데이터가 불완전함
- 연구정원의 서식지 설계가 잠겨 있음
- 식물 연구 결과를 생활 문제 해결에 활용한 최종 연구 성과가 검증되지 않음

그린코어는 잘못된 정보로 식물을 자동 배치하지 않기 위해 연구기지를 정지시킨다.

학생은 **초록정원 연구원**이 되어 식물 연구 Evidence 5종을 다시 확보하고, 직접 정원을 복구한 뒤 최종 시운전을 통과해야 한다.

## NPC 의뢰

### 리피 — 식물 기록 연구원

- 메인 퀘스트 의뢰
- 식물 표본 관찰 및 분류 지원
- Evidence 보관함 관리
- Final Report 진행

시작 대사:

> “그린코어가 식물 기록을 믿지 못해서 멈춰 버렸어.  
> 우리가 직접 관찰하고 확인한 연구 결과가 필요해.”

### 방울 — 환경 실험 파트너

- 물 환경 실험 파트너
- 환경 조건 비교
- 정원 지형 설계 반응
- 실험 실패 시 관찰 단서 제공

### 꽃이 — 생활 기록·설계 파트너

- 계절 변화 기록
- 주장과 증거 정리
- 식물 특징 활용 아이디어 지원
- 설계 결과 소통

## 최종 목표

```text
Evidence 1  표본 관찰·분류 기록
Evidence 2  계절 생활 증거 카드
Evidence 3  환경-특징-생활 방식 연결 보고서
Evidence 4  연구정원 설계도
Evidence 5  식물 아이디어 테스트 보고서
```

이 5종의 Evidence를 그린코어에 제출한 뒤 학생이 직접 **최종 생태 코어 시운전**을 수행하면 연구기지가 100% 복구된다.

# ④ Mission 1~5 심화 설계표

## Mission 01 — 뒤섞인 식물 기록을 정리하라

| 항목 | 내용 |
|---|---|
| 학습목표 | 식물의 잎 특징을 관찰하고 명확한 기준을 정하여 분류한다. |
| 퀘스트 상황 | 그린코어가 식물 표본을 구별하지 못해 모든 기록을 임시 잠금했다. |
| 학생 핵심 행동 | 확대 관찰 → 특징 기록 → 기준 생성 → 분류 → 규칙 수정 |
| 주요 상호작용 | Pinch Zoom, Rotate, Hotspot, Drag, Rule Builder |
| Micro Loop | 관찰 → 특징 발견 → 규칙 생성 → 분류 실행 → 모순 확인 → 규칙 수정 → 재실행 |
| 실패/재시도 | 애매한 기준이나 잘못된 분류는 X가 뜨지 않고 두 그룹의 기록이 충돌하는 현상으로 표시 |
| 과학적 피드백 | 같은 기준이면 누구나 같은 결과가 나와야 함을 분류 결과로 확인 |
| 획득 Evidence | **표본 관찰·분류 기록** |
| World Change | 표본 보관소 라벨과 분류 패널이 다시 켜짐 |
| 유지 | 1-1 식물 표본 스캔, 1-2 분류 규칙 연구실 |
| 개선 | 단순 드래그 → 규칙 실행·모순 탐지·재분류 루프 강화 |

## Mission 02 — 계절 생활 기록을 이어 붙여라

| 항목 | 내용 |
|---|---|
| 학습목표 | 식물의 계절별 모습을 비교하고 여러 해를 사는 식물의 생활 모습을 관찰 근거로 설명한다. |
| 퀘스트 상황 | 계절 기록이 서로 다른 날짜로 섞여 그린코어가 식물의 생활 기록을 연결하지 못한다. |
| 학생 핵심 행동 | 계절 스크럽 → 비교 → 주장 확인 → 증거 연결 |
| 주요 상호작용 | Timeline Scrub, Split Compare, Evidence Linking |
| Micro Loop | 계절 이동 → 변화 관찰 → 증거 선택 → 설명 연결 → 부족한 증거 확인 → 다시 관찰 |
| 실패/재시도 | 근거가 약하면 설명 흐름이 완성되지 않으며 해당 계절로 다시 이동해 관찰 가능 |
| 과학적 피드백 | 잎이 떨어져도 줄기·뿌리 등이 남아 다음 계절까지 이어지는 모습을 화면 변화로 확인 |
| 획득 Evidence | **계절 생활 증거 카드** |
| World Change | 계절 관찰 돔의 시간 장치가 정상 작동 |
| 유지 | 2-1 계절 관찰 타임랩, 2-2 생활 증거 분석실 |
| 개선 | 정답 카드 선택 → 실제 타임라인 관찰 기록을 근거로 사용 |

## Mission 03 — 환경과 식물의 관계를 검증하라

| 항목 | 내용 |
|---|---|
| 학습목표 | 서로 다른 환경의 식물 생김새와 생활 방식을 조사하고 환경과의 관련성을 설명한다. |
| 퀘스트 상황 | 수생·건조 환경 데이터가 섞여 그린코어의 서식지 판정 기능이 정지했다. |
| 학생 핵심 행동 | 부레옥잠 가상 절단·관찰·누르기 → 환경 비교 → 식물 배치 → 근거 연결 |
| 주요 상호작용 | 3D Observation, Virtual Cut, Press, Long Press, Drag, Evidence Chain |
| Micro Loop | 예상 → 실험 → 현상 관찰 → 환경 판단 → 배치 → 근거 연결 → 오류 수정 |
| 실패/재시도 | 잘못 배치 시 빨간 X 대신 근거 체인이 끊어지고 환경 특성을 다시 확인하게 함 |
| 과학적 피드백 | 공기 방울, 떠 있는 상태, 두꺼운 잎 단면 등 실제 관찰 가능한 현상으로 피드백 |
| 획득 Evidence | **환경-특징-생활 방식 연결 보고서** |
| World Change | 수생 실험 수조와 건조 환경 챔버가 재가동 |

## 화면 1 — 1-1 식물 표본 스캔

### 화면 목적
식물 이름을 맞히기 전에 **관찰 가능한 특징을 실제로 찾아 기록**한다.

### 학생에게 보이는 상황
표본 보관소에서 식물 데이터의 일부가 비어 있다. 3개의 식물 표본 중 하나가 확대 장치에 놓여 있고 특징 데이터는 잠겨 있다.

### 학생 행동
1. 표본을 확대한다.
2. 필요한 경우 회전한다.
3. 잎 모양·가장자리·잎자루·잎맥을 직접 확인한다.
4. 발견한 특징을 연구 노트에 기록한다.
5. 다른 표본과 비교한다.

### 태블릿 조작
Pinch Zoom / Rotate / Tap Hotspot / Long Press Detail / Swipe Specimen Change

### 화면 반응
- 확대 정도가 충분해야 세부 특징 핫스폿 활성화
- 발견한 특징만 연구 노트에 자동 해금
- 동일 위치를 다시 확대하면 비교표가 열림
- 모든 특징을 찾기 전에는 분류 Mission으로 넘어갈 수 없음

### 과학 개념
식물은 잎 모양, 가장자리, 잎자루, 잎맥 등의 특징이 서로 다르다.

### 실패·재시도
특징을 확인하지 않고 추측으로 기록하면 “확인 필요” 상태가 되고 해당 표본으로 다시 포커스한다.

### 성공 조건
지정 표본의 필수 특징을 모두 관찰하고 2개 이상의 표본을 비교.

### 필요한 이미지 에셋
식물 표본 3종 / 핵심 확대 표본 1종 / 확대경·스캔 프레임 / 리피 / 방울 / 온실 연구실 배경

### CSS/UI 요소
헤더 / 오늘의 연구 / 연구 노트 / 특징 칩 / 진행 표시 / 툴팁 / 하단 힌트

### 3D
**권장.** 식물 또는 잎 표본을 가벼운 3D·pseudo-3D viewer로 구현한다. 회전 자체가 목적이 아니라 관찰 지점을 찾는 데 사용한다.

- 식물 배치 상태 확인

## STEP 4 — 연구 활용 모듈 적용

## STEP 5 — 코어 가동

```text

```

세 링이 일치하면 그린코어가 실제로 밝아지고 연구기지 전체가 가동된다.

# 15. 캐릭터 심화 설계

## 리피
식물 잎을 모티프로 한 작은 연구 안내자.

- 잎 모양 후드 또는 잎 망토
- 따뜻한 둥근 얼굴
- 작은 연구 가방
- 확대경
- 초록·크림 계열

기능: 메인 퀘스트 제공 / 표본 관찰·분류 지원 / 연구 노트 확인 / Final Report 진행.

## 방울
물방울을 모티프로 한 환경 실험 파트너.

기능: 수생 환경 관찰 / 물 관련 실험 반응 / 지형 설계의 물가 구역 상태 설명 / 실험 결과 해석.

## 꽃이
꽃봉오리·꽃잎을 모티프로 한 생활 기록·아이디어 파트너.

기능: 계절 변화 관찰 / 증거 정리 / 식물 특징 활용 아이디어 촉진 / Final 제품 설명.

### 캐릭터 등장 원칙
한 화면에 1~2명 권장. 완료·Final 장면에서만 3명 동시 등장 가능.

**부엉이와 로봇 캐릭터 사용 금지.**

# 27. 과학적 정확성 안전선

1. 식물이 학생의 선택에 따라 즉시 “진화”하는 표현 금지.
2. 3학년 수준에서는 `적응`을 중심 개념으로 직접 가르치지 않는다.
3. 식물이 의도적으로 자신을 바꾼 것처럼 표현하지 않는다.
4. 환경과 식물의 생김새·생활 방식 사이 **관련성**을 관찰하게 한다.
5. 부레옥잠 실험은 관찰 가능한 공기 방울과 떠 있는 모습 연결에 초점을 둔다.
6. 실제 제품 사례와 학생의 창작 아이디어를 구분한다.
7. 확인되지 않은 발명 인과를 단정하지 않는다.
8. 테스트 시뮬레이션은 실제 과학의 완전한 물리 모델이 아니라 **학습 목표를 위한 규칙 기반 모델**임을 내부 설계에 명시한다.

# 31. 개발 완료 판단 기준

- 5개 Mission이 하나의 사건으로 연결된다.
- 각 Mission에서 Evidence를 획득한다.
- Mission 결과가 메인 기지에 남는다.
- 10개 화면에서 동일한 조작 패턴을 반복하지 않는다.
- 각 화면에서 학생 행동이 화면 현상을 변화시킨다.
- 빨간 X와 정답 팝업 없이도 결과를 이해할 수 있다.
- 최소 3개 화면에서 즉시 수정·재시도가 가능하다.
- 학생이 만든 정원과 발명품이 저장된다.
- Final Report에서 5개 Evidence가 다시 보인다.
- Final Mission에서 학생이 직접 그린코어를 재가동한다.
- Final Movie가 학생의 연구 결과를 반영한다.
- 인증서가 Mission 5/5, Evidence 5/5, 탐구 스타일을 표시한다.
- 부엉이·로봇 캐릭터가 없다.
- 캐릭터는 실제 기능이 있는 장면에만 등장한다.
- UI는 CSS/DOM 중심으로 구현 가능하다.
- 핵심 이미지 에셋은 화면당 약 10개 이하를 유지한다.
