# 2026-10-15 캐릭터·발명 조작·보상 개편 계획

## 해결할 문제

캐릭터 시트의 불투명 패널까지 CSS로 잘라 사용해 발끝과 바깥 잎이 잘렸다. 긴 설명을 읽고 확인 버튼을 누르는 발명 단계는 조작의 목적과 결과가 눈에 잘 드러나지 않았다. 완료 보상은 문구 중심이라 정원을 되살리는 목적과 연결이 약했다.

## 구현 방향

1. 원본 정체성을 유지한 캐릭터 3종을 독립 투명 PNG로 분리하고 실제 알파 픽셀·가장자리·발끝을 검증한다. 전체 이미지를 contain으로 표시하고 시트 좌표 크롭을 제거한다.
2. 지도 바탕과 복구 시설 5종을 생성한다. 처음에는 잠든 시설, 탐구 후에는 색과 불빛이 돌아온 시설을 지도와 보상 화면에 같은 그림으로 보여 준다.
3. 발명은 큰 그림 부품 선택 → 비 뿌리기 → 가방 안 수첩/겉면 결과 확인 → 같은 화면에서 수정한다. 기존의 숨은 설명 확인 버튼 대신 짧은 특징 연결 질문을 쓴다. 두 기능을 섞어 설명하지 않는다.
4. 보상은 실제 완료 기록에서만 계산하는 빛씨앗 5개. 반복 완료나 관리자 해금으로 씨앗을 늘리지 않는다. 새로고침·기존 기록도 유지한다.
5. 계절 탐구 보상으로 꽃길 색 선택을 열어 지도와 완성 정원에 반영한다. 선택은 장식이며 학습 완료에 필수로 요구하지 않는다. 정원 미션의 실제 지형·식물은 이후 지도와 엔딩에 계속 보인다.

## 단계별 인과

| 탐구 | 화면에서 생기는 변화 | 다음 행동을 기대하게 하는 요소 |
|---|---|---|
| 관찰·분류 | 표본 온실 복구 + 빛씨앗 1 | 다음 계절 돔이 열리고 관찰 기록은 수첩에서 다시 볼 수 있음 |
| 계절·생활 | 계절 돔 복구 + 꽃길 선택 + 빛씨앗 1 | 고른 꽃길이 지도에 나타나며 환경 실험실 개방 |
| 환경·특징 | 물길 실험실 복구 + 빛씨앗 1 | 관찰한 환경을 내 정원 지형으로 만드는 활동 개방 |
| 정원 만들기 | 내가 그린 지형·배치가 실제 지도에 등장 + 빛씨앗 1 | 자신의 식물과 장소를 지키기 위한 발명 공방 개방 |
| 발명·개선 | 시험으로 고친 가방 + 공방 복구 + 빛씨앗 1 | 씨앗 5개와 실제 연구 기록으로 마지막 그린코어 가동 |

## 검증할 것

투명도와 크롭, 모든 핵심 조작의 48px 터치 영역, 미완료 보상 차단, 반복 보상 중복 방지, 꽃길 저장 복원, 실패→수정→성공 가방 비교, 기존 저장 호환, 모바일/태블릿 레이아웃, dist 재빌드 및 현재 미리보기 반영.
