## 외형과 등장

**모종 빼돌리는 악당 / V2 화분 실루엣과 기존 표르의 표찰 가면 비교, 뿌리 흙덩이가 단서.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

기존 표르와 리피 시트 재사용 우선. 기록된 체력·재도전 룰은 이번 3회·피격 연출안과 다르므로 실제 구현 확인 후 충돌 범위를 검토한다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 식물 기록 보관소 | 잎 표찰을 숨겼다가 뒤집어 내밀기 | “그 표찰은 어디 갔을까?” |
| 계절 관찰 돔 | 계절 표식을 거꾸로 돌리기 | “계절을 뒤집어 버렸지!” |
| 환경 실험실 | 화분 표지 막대 옮기기 | “여기 있어야 할 팻말은 아니야!” |
| 우리의 연구정원 | 뿌리 흙째 모종 들고 뒷걸음 | “이 모종은 내 거야!” |
| 식물 발명 공방 | 잎 모형 부품을 빼서 뒤에 숨기기 | “이 부품은 잠깐 압수!” |

상황 대사 예시:

- 접근: “모종을 살짝 옮겼을 뿐이야!” / “뿌리 흙까지 꽁꽁 숨겨야지!”
- 1·2타: “앗, 흙이 떨어졌어!” / “잎이 간질간질해!”
- 퇴장: “모종은 두고 갈게!” / “낙엽 사이로 쏙!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 얇은 잎 한 장이 뒤집힘 |
| 2타 · 더 큰 반동 | 뿌리 흙이 짧게 톡톡 |
| 3타 · 마무리와 퇴장 | 잎 소용돌이에 표찰 가면이 들렸다가 악당이 빠져나감 |
| 주인공 접촉 | 리피는 손으로 얼굴 앞을 가리고 한 발 물러남 |
| 보조 캐릭터 접촉 | 동료는 잎이 살짝 눕고 몸을 낮췄다가 회복 |
| 악당의 접촉 공격 동작 | 잎을 몸 뒤로 접었다 한 번 휘두름. 닿은 쪽 발밑에 흙점 두 개만 남김. |
| 타격·퇴장 효과음의 차이 | 사각 → 툭툭 → 사르륵 |
| 접촉 효과음 모티프 | ‘사각’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 표르의 표찰과 뿌리 흙덩이는 제자리에서 읽혀야 한다. 리피가 건너편으로 이동해도 모종이 손을 바꾸거나 공중에 튀지 않도록 좌우 손 프레임을 확인한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/model.js](../src/model.js) · [src/stage-map.js](../src/stage-map.js) · [docs/MAP-COMBAT-20261109.md](../docs/MAP-COMBAT-20261109.md). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
