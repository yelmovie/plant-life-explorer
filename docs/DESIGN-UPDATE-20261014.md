# 제작·기능 개선 기록

## 의도

사용자가 요청한 방향은 향후 3D로 교체할 기본 그림과 아기자기한 교육 게임의 완성도였다. 학습 구조를 전면 변경하지 않고, 기존 캐릭터와 녹색·크림색을 유지하며 학습 대상이 더 잘 보이도록 개선했다.

## 제작

목록 10종과 보충 7종을 내장 이미지 생성 도구로 만들었다. 잎은 모양·가장자리·잎맥이 읽히도록, 단면은 내부 공간과 조직이 구분되도록, 가방은 열린/닫힌 입구가 눈에 보이도록 제작했다. 투명 PNG 원본과 압축 WebP를 D: 프로젝트에 보관했다. 계절 변화·최종 붓꽃 도식은 설명용 SVG를 유지했다.

## 화면과 기능

큰 그림과 조작 도구를 왼쪽, 관찰 기록을 오른쪽에 두고 작은 화면에서는 순서대로 쌓았다. 학습 안내·본문·보조 정보의 글자 크기를 구분하고 큰 글자 모드를 별도로 보강했다. 실험은 단계별 표본 교체, 가방 시험은 진행 중 표시와 현재 설계의 결과로 연결했다.

실제 플레이 검증에서 보고서 영속화, 변경된 산출물의 완료 상태, 시험 중 이동 취소, 가방 장식 SVG 크기 충돌을 점검·수정했다. CSS 치수 검사만으로 잡기 어려운 장식 위치는 실제 캡처로 확인했다.

## 다음 제작자에게
