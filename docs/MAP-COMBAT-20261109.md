## 구현
- 완료한 탐구 구역만 표르를 생성한다. 나무 표찰 가면·보라 리본·자주색 목도리의 장난감 악당이다.
- 기존 길의 거리 좌표에서 추적, 공격 전조, 돌진, 접촉 피해를 처리한다. 리피의 실제 지도 이동과 연동한다.
- Space/J/92×64 공격 버튼, 근접 거리·방향 판정, 쿨다운, 체력4, 무적1.3초, 피격 밀림, 재도전.
- 학습 완료·해금·보상에는 쓰지 않는다. mapVillains는 격퇴한 구역에만 3을 저장하며 기존 저장과 시연 분리를 유지한다.
- 표르를 누르는 입력은 없으며 전투용 카드/모달을 만들지 않는다. 전투 가까이에서는 자동 입장 팝업을 잠시 억제하지만 장소 버튼을 직접 누른 입장은 유지한다.
- 각 구역의 복구 알림은 잎 분류 → 겨울·봄 → 환경 → 정원 → 발명 가방이라는 기존 학습 흐름을 따른다.
