# 리피의 정원 구조대 · 고도화 설계

사용자 승인: 2026-10-20. 기존 학습 기록과 제작 중인 화면·음향 변경을 보존한다. 새 수업에서 탐구를 시작한 미션은 현장 임무의 증거도 완료 조건에 포함한다.

## 학생이 이해할 목표

리피와 함께 식물의 비밀을 찾아, 뒤섞인 식물 기록과 정원을 복구한다. 화면은 한 번에 한 가지 행동을 말하고, 실제로 바꾼 결과가 장면과 연구 노트에 남는다.

| 미션 | 성취기준 연결 | 직접 하는 일 | 비교·적용 | 보상과 다음 사용 |
|---|---|---|---|---|
| 잎 서랍 | 4과03-01 관찰·특징에 따른 분류 | 확대경 이동, 표본 분류 | 다른 잎과 두 기준 | 관찰 렌즈 → 겨울 식물 관찰 |
| 사라진 봄 | 4과03-02 환경과 식물 생활 | 시간 이동, 사진·연결·순서 배치 | 나무와 풀의 겨울·다음 봄 | 계절 관찰 수첩 → 예상·전후 실험 기록 |
| 물길 실험 | 4과03-02 특징과 환경 관계 | 예상, 수조에 모형 넣기, 잎자루 절개·누르기 | 공기 포함 모형과 비교 모형 | 물주기 병 → 정원의 물 조건 확인 |
| 살아 있는 정원 | 4과03-02 환경에 맞는 생활 | 환경 만들기, 식물 심기 | 바뀐 조건에 다시 적용 | 정원 도구 꾸러미 → 식물 특징을 발명 단서로 가져오기 |
| 탐험 가방 | 4과03-03 특징 활용 설계·소통 | 부품 조립, 같은 비 시험 | 한 부품만 다른 두 결과 비교 | 내 가방·배지·복구 정원 전시 |

성취기준 원문은 기존 설정의 세 기준을 유지한다. 공식 고시 확인: [교육부 2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=040401&opType=N). 게임 속 겨울·봄 탐구는 식물의 환경과 생활을 비교하는 활동이며 식물의 한살이 전체를 이 단원에서 평가하지 않는다.

## 흐름과 보상

지도에서 길을 따라 방문 → 리피의 짧은 부탁 → 현장 임무(세 가지 조작·판단) → 두 활동의 연구 증거 → 장소 복구·빛씨앗·도구. 누른 횟수·속도·대기 시간은 완료 근거가 아니다. 예상이 틀렸다는 이유로 벌점을 주지 않는다. 도구와 보상은 실제 완료 기록에서 계산하며 재방문으로 중복 지급하지 않는다.

현장 임무와 기존 연구 화면은 서로 전환할 수 있다. 완료한 기존 학습 기록은 새 조건 때문에 취소하지 않는다. 교사용 미리보기의 답변·도구·완료는 학생 저장본에 쓰지 않는다.

## 시각·과학 원칙

원래 리피를 모든 스테이지의 문제 해결 동료로 사용한다. 그림 장면을 크게 두고 실제 도구·실험이 화면의 중심이 되게 한다. CSS 상자는 읽기·조작에 필요한 경우로 한정한다. 부레옥잠의 잎과 부푼 잎자루를 구분하고, 단면의 공기 공간을 두께 있는 입체 모형으로 보여 준다. 부력 비교는 원리 확인용 모형 실험임을 명시한다. 연잎 표면과 가방 덮개의 기능을 혼동시키지 않는다.

## 검증

각 미션의 잘못된 조작 → 관찰 가능한 결과·단서 → 수정, 신규 조건을 건너뛴 완료 차단, 저장 왕복, 기존 완료 보존, 교사용 격리, 마우스·키보드·터치 에뮬레이션, 태블릿 화면, 실제 렌더·콘솔·빌드를 확인한다. 학생 이해도·자발적 재방문·실제 소요 시간은 교실 관찰 전까지 미측정이다.

실제 보상 그림과 이름을 맞췄다. 획득한 도구의 단서 꺼내기 버튼은 겨울 땅속 관찰·예상과 실제 기록·정원의 물 조건·한 부품 비교의 관찰 방향을 제공한다. 답이나 완료 기록을 대신 채우지 않는다.
