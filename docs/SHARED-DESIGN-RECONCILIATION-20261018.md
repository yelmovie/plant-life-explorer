## 적용 원칙

- 5미션·10활동 유지. 초기 브레인스토밍의 씨앗 로봇·카메라·7번째 미션은 넣지 않는다.
- 리피가 모든 미션을 연결하고 방울·꽃이는 실험·계절·설계 역할을 맡는다.
- 점수·속도·클릭 횟수로 보상하지 않고 관찰 근거, 수정, 비교와 산출물로 보상한다.
- 3D는 관찰·단면·배치·물길을 직접 보기 위한 단순화 모형이다. 실제 생육·유체·부력 예측을 주장하지 않는다.
- 복잡한 드래그가 필수 통과 조건이 되지 않도록 탭·키보드 대안 유지.
- 큰 장면과 조작 도구 중심. 안내는 현재 행동 하나, 자세한 기록은 필요할 때 연다.
- 저장돼 있던 완료·보상은 삭제하지 않는다. 새 활동의 증거를 과거 기록에 임의로 추가하지 않는다.

## 실행 계획

1. 길을 따라가는 지도·계절 관찰·발명 작업장 이미지 생성·적용.
2. 분류 실행·충돌 수정, 두 식물의 시간·증거, 실험의 예상·관찰 연결 보강.
3. 표본·잎자루·정원·가방의 직접 조작 및 입체 장면, 그림·격자 대안 구현.
4. 캐릭터 의뢰·기록·장소 복구와 다음 길의 연결.
5. 저장·학습 판정·해상도·빌드·실제 브라우저 흐름을 final-check로 검증.

실제 완료·측정 범위·남은 제한은 최종 검수 보고서에 구분한다.
