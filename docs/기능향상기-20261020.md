# 2026-10-20 디자인·설정 개선

디자인·최종점검·아이스크림 설정 스킬로 화면과 실행 경로를 함께 점검했다. 기존 생성 이미지와 10개 활동 배경이 충분해 새 이미지는 만들지 않았다.

## 화면에서 바뀐 것

- 공통 메뉴를 홈·이전·소리·설정 네 개로 정리하고, 다른 도구는 설정 안으로 옮겼다.
- 지도의 기본 카메라가 화면을 채우도록 바꾸었다. 길 따라 이동과 전체 지도 보기는 유지한다.
- 활동면을 반투명하게 바꾸고, 작은 화면에서 분류·계절·환경 연결·정원을 다시 배치했다.
- 가방의 연잎 특징을 연결한 뒤에는 예상 선택을 먼저 보여 준다. 이미 확인한 설명은 다시 펼쳐 볼 수 있다.
- 가방 시험의 전후 기록·이유 선택이 작은 화면에서도 함께 보이도록 구성했다.
- 최종 적용 문제의 선택지와 정원 깨우기 버튼을 독립된 행으로 나누었다.
- 잎 관찰에서 틀린 뒤에는 다시 관찰할 수 있는 버튼을 바로 보여 준다.

## 실행에서 고친 것

없는 벚나무 GLB 요청을 제거하고 기존 모형을 사용한다. 모형·텍스처를 불러오지 못하거나 WebGL을 사용할 수 없을 때는 그림을 보여 준다. 공유 텍스처의 늦은 로딩과 다중 터치 취소도 정리했다.

음악과 효과음 설정을 분리했다. 실제 음악 파일은 없어 음악 스위치와 음량은 비활성화하고 이유를 표시한다. 효과음 연타·탭 숨김을 처리하고 탐구 기록 초기화 후에도 소리 선택을 유지한다. 교사용 열기로 학생 완료 기록이나 엔딩 권한을 만들지 않는다.

## 확인한 결과와 한계

자동 테스트 53개와 문법 검사, 배포 빌드를 통과했다. 873×580·906×755·1280×800·1920×1080에서 10개 활동과 메인·지도·보고·최종·엔딩을 확인했다. 직접 쓸어 5칸을 칠하고 한 번에 되돌리기, 잎자루 쓸어 자르기, 분류 근거 수정과 보상, 계절 사진 연결, 가방 한 부품 시험과 최종 적용을 조작했다.

실제 학생의 학습효과와 재방문 의향, 실물 태블릿의 다중 터치, 교실 와이파이·완전 오프라인 진행은 아직 확인하지 않았다. 점수와 조건은 `reviews/FINAL-CHECK-20261020.md`, 크기별 화면·실측은 `reviews/design-20261020/`에 남긴다.
