# 아이콘 제작·재사용 기준 (2026-10-20)

현재 UI 아이콘은 `src/art.js`의 `icon()`이 직접 그리는 SVG다. 설치 아이콘은 기존 리피 그림을 가공했고, 새 AI 이미지를 만들지 않았다. 아래 내용은 실제 생성 기록과 향후 제작 지침을 구분한다.

## 현재 쓰는 아이콘

| 파일·키 | 용도 | 제작 방식 |
|---|---|---|
| `home`, `back`, `sound`, `muted`, `gear`, `close` | 공통 이동·소리·설정·닫기 | 직접 작성 SVG 경로, 24×24 viewBox·둥근 선 끝·`currentColor` |
| `arrow`, `check`, `lock`, `undo`, `reset` | 진행·확인·잠금·되돌리기·초기화 | 같은 SVG 함수 |
| `leaf`, `book`, `flag`, `flask`, `spark`, `sun`, `drop` | 연구 기록·탐험·보상·환경 | 같은 SVG 함수 |
| `zoom`, `rotate`, `expand`, `camera`, `print`, `circle` | 관찰·입체 조작·저장·인쇄 | 같은 SVG 함수 |
| `assets/icons/icon-192.png`, `icon-512.png` | 설치형 앱 아이콘 | `mascot_leaf`를 축소해 바탕색 위에 배치한 기존 가공본 |
| `index.html`의 `data:image/svg+xml` | 브라우저 탭 아이콘 | 코드로 작성한 잎 실루엣 |
| `generated/stamp_direct`, `stamp_fixed`, `stamp_complete` | 발견·수정·완료 도장 | 2026-10-19 Higgsfield GPT Image 2.5 생성 기록. UI 메뉴 아이콘과 별개 |

## 재사용 원칙

- 조작 아이콘은 SVG로 유지한다. 이미지 생성으로 버튼 전체·글자·상태 표시를 구워 넣지 않는다.
- 아이콘 색·크기·배경·눌림 상태는 CSS 토큰으로 조정한다. 실제 클릭 영역은 그림 크기와 별개로 확보한다.
- 뜻은 버튼의 한글 `aria-label`과 필요한 화면 문구로 전달한다. SVG는 장식이므로 `aria-hidden="true"`를 유지한다.
- 운영체제마다 다른 이모지는 공통 조작 아이콘으로 사용하지 않는다.

## 향후 새 장식 도장이 필요할 때의 프롬프트 초안

> 기존 초록정원 도장과 어울리는 작은 식물 연구 배지 한 개. 둥근 모서리, 짙은 숲색과 옅은 새싹색, 부드러운 입체감, 정면 구도, 알아보기 쉬운 단일 상징, 모든 외곽이 잘리지 않게 여백 확보. 글자·숫자·로고·버튼 테두리·UI 패널 없이 실제 투명 배경. 기존 캐릭터를 넣는다면 제공한 캐릭터의 얼굴·옷·색·비율을 유지.

이 프롬프트는 새로 실행한 생성 기록이 아니다. 생성이 필요해지면 사용한 서비스·날짜·입력 참조·결과 파일을 `assets/CREDITS.md`에 추가한다.
