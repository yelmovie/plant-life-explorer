# 탐구 흐름 점검 · 2026-11-15

| 구간 | 반복이 생기던 지점 | 이번 변경과 남은 제안 |
| --- | --- | --- |
| 시작·지도 | 지도 이동, 도착 팝업, 입장 버튼이 연달아 나오면 같은 목적지를 고르는 느낌이 난다. | 기존 「다음 탐험」 바로가기와 이어하기를 유지. 입장 대기가 수업에서 길게 느껴지면 지도 이동은 선택, 다음 탐구는 한 번에 입장하도록 점검. |
| 1장 잎 | 톱니 분류를 현장과 본 탐구에서 반복하고 낱장마다 같은 질문을 했다. | 현장 톱니 분류 한 번, 세 잎 함께 확대, 은행잎 짝을 한 번 골라 기준별 묶음 비교. |
| 2장 계절 | 같은 두 식물의 겨울과 봄을 다시 찾아 사진 네 장을 찍고, 식물별로 답했다. | 현장 그림 네 장을 한 화면에 놓고 다시 자란 부분을 한 번 비교. 현장 타임 다이얼과 땅속 관찰은 유지. |
| 3장 부레옥잠 | 현장에서 연 잎자루를 본 탐구에서 다시 자르고 물에 넣었다. | 물속에서 누르기부터 시작하고, 나온 공기가 뜨는 데 어떻게 도움이 되는지 연결. 뒤에서는 세 식물의 사는 곳과 특징을 한 화면에 놓고, 잎에 물을 저장하는 식물을 한 번 고름. |
| 4장 정원 | 현장에서 환경을 만들고 심은 뒤 본 탐구의 빈 땅에 다시 칠하고 심었다. | 현장 정원을 이어받아 한 자리만 확인하거나 옆 자리로 옮기고 까닭을 선택. |
| 5장 공방 | 현장 시험 뒤 가방을 돌려야 했고, 본 탐구에서 또 비를 내려야 했다. | 같은 비로 네 가방을 시험한 기록을 바로 비교하고 두 부품의 역할을 한 번 선택. |
| 연구 노트·엔딩 | 일부 기억 퀴즈는 방금 고른 결론을 다시 묻는다. | 기억 퀴즈는 접어 두고 원하는 학생만 「기억 퀴즈 · 선택」을 눌러 풀 수 있다. 선인장 문제는 새 식물 적용이라 유지. |

실제 학생의 체감 시간이나 흥미도는 수업에서 따로 확인한다.
