## 중복 조작 버튼

| 화면 | 중복 | 처리 |
|---|---|---|
| 탐구 기록 2/2 (8화면: 1·2·3·4·5장 기록 2) | 아래 「← 앞 활동」 = 왼쪽 위 「←」(같은 앞 기록 화면으로 감) | 아래 버튼을 뺌. 사진이 없어 앞 활동으로 돌아가야 할 때(안내 손가락이 그 버튼을 가리킬 때)만 보임 |
| 연구 노트 창 | 위 X = 아래 「노트 덮기」 | 위 X 숨김(Esc·노트 덮기로 닫힘). 다른 창의 X는 브라우저 테스트가 쓰는 닫기라 유지 |
| 5장 현장 2단계 | 이미 비를 맞은 가방 위 구름에도 「비 내리기!」 글자 → 눌러도 「이 가방은 벌써 시험했어」만 나옴. 실제 비는 가방 카드가 내림 | 시험을 마친 가방(`data-rain="skip"`)에서는 구름 글자만 숨김(구름 그림·비 연출은 그대로) |

검토했지만 남긴 것(보수적 판단):

- 잎자루 화면의 그림 누르기 + 오른쪽 「잎자루 눌러 보기」: 3D가 켜진 기기에서는 그림 버튼 대신 입체 장면이 놓이고, 같은 오른쪽 버튼 자리가 앞 단계의 「잎자루 잘라 보기」「물속에 넣기」도 맡는다. 브라우저 테스트도 그 버튼을 쓴다. 유지.
- 계절 바꾸기의 시간 손잡이 + 계절 이름 버튼: 손잡이 눈금 이름표 구실이고 안내 손가락이 이름 버튼을 가리킨다. 유지.
- 지도의 장소 핀 + 오른쪽 아래 「○○로 가기」: 프로젝트가 지킬 좋은 점(3초 문서)으로 정해 둔 배치. 유지.
- 5장 현장 가방 카드 세 장의 「톡! 비 내리기」: 서로 다른 가방을 고르는 판단 선택지. 유지.
